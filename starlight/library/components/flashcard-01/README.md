# FlashCard-01

限时秒杀与促销单品卡片组件，基于原生 Web Component 构建。集成正方形主图骨架、高饱和度折扣角标、原价现价对比、库存售罄进度条与抢购按钮。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 卡片宽度随容器网格列或 Swiper 幻灯片等比缩放，图片固定 1:1 高宽比。
- 响应式自适应适配桌面与移动端，保持倒计时与售罄进度条清晰易读。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `product-id` | 秒杀商品唯一标识符 | `string` | `'flash-01'` |
| `sold-percent` | 已售库存百分比 | `number` | `65` |

### 事件机制
- `product-navigate`: 点击秒杀卡片时派发商品跳转事件。
- `flashcard-buy`: 点击立即抢购按钮时派发抢购提交事件。
