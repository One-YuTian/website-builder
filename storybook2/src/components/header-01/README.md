# Header-01

Responsive sticky header with dual-tier navigation on desktop and a slide-out navigation drawer on mobile. Inherits global theme typography, colors, radii, and container breakpoints.

## Attributes

| Attribute | Property | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `is-logged-in` | `isLoggedIn` | boolean | `false` | Displays authenticated navigation items and account dropdown when present. |
| `cart-count` | `cartCount` | number | `0` | Item count badge for the cart action icon. |
| `wishlist-count` | `wishlistCount` | number | `0` | Item count badge for the wishlist action icon. |
