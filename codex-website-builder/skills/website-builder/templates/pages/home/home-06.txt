## Overview

Luxury timepiece and elegant accessory boutique homepage assembled from minimalist luxury navigation header, premium hero carousel, dual promotional grid, visual brand story banner, classic watch showcase, and warranty footer.

### Component Chain
`home-06: header-06 -> carousel-03 -> promotion-03 -> promotion-10 -> productlist-03 -> footer-02`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-06` | `<header-06>` | Minimalist luxury sticky navigation header highlighting brand elegance |
| `Carousel-03` | `<carousel-03>` | Hero responsive full-width carousel presenting high-end visual showcases |
| `Promotion-03` | `<promotion-03>` | Dual-tile promotional feature grid for collection spotlights |
| `Promotion-10` | `<promotion-10>` | Brand collection visual story banner highlighting craftsmanship |
| `ProductList-03` | `<productlist-03>` | Classic timepiece and accessory showcase grid with refined card layouts |
| `Footer-02` | `<footer-02>` | Global site footer with warranty certifications, trust badges, and navigation |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
