## Overview

Contact Us communication and inquiry page, containing page title skeleton, online feedback inquiry form (Name, Email, Subject, Message), office address / hotline / business hours info cards, and map placeholder area.

### Layout & Regions
- `page-header`: Page header title and consultation intro text skeleton.
- `contact-form`: Visitor inquiry form and submit button.
- `info-cards`: Physical store address, hotline, support email, and working hours cards.
- `map-area`: Map geographic location placeholder skeleton.

### Dimensions & Responsiveness
- Follows global design system, outer container uses `content-container` with PC max content width 1200px centered.
- Desktop (1024px+): Two-column layout with form on left and info cards on right.
- Mobile (under 1024px): Single-column vertical layout with 100% width inputs.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `submitted` | Form submission success state | `boolean` | `false` |

### Events
- `contact-submit`: Dispatched when submitting the contact inquiry form.

### JavaScript

```javascript
$(function() {
  $('#contact-message-form').on('submit', function(e) {
    e.preventDefault();
    const firstName = $('#first-name').val();
    const lastName = $('#last-name').val();
    const email = $('#email').val();
    const message = $('#message').val();

    const event = new CustomEvent('contact-submit', {
      bubbles: true,
      composed: true,
      detail: { firstName, lastName, email, message }
    });
    this.dispatchEvent(event);

    $(this).find('input, textarea').val('');
  });
});
```
