# WelcomeModal-01

新人首单礼欢迎弹窗板块，包含半透明遮罩、礼品盒图标骨架、新人立减优惠券面额大标题、邮箱订阅表单以及领取 CTA 按钮。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 弹窗最大宽度 480px，自适应视口高度居中显示，遮罩覆盖全屏。
- 移动端：自适应宽度为 calc(100vw - 32px)，保持内边距紧凑。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `discountText` | 优惠券大标题文案 | `string` | `'15% OFF'` |
| `isOpen` | 弹窗展示显隐状态 | `boolean` | `true` |

### 事件机制
- `modal-close`: 点击关闭叉号或遮罩层时派发关闭事件。
- `modal-submit`: 提交订阅邮箱领取优惠券时派发。
