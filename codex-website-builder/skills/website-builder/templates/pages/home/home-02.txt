## Overview

Southeast Asian comprehensive multi-category e-commerce homepage assembled from promo-focused navigation header, hero responsive banner carousel, bestsellers product grid, visual promotional banner, personalized recommendation feed, and site footer.

### Component Chain
`home-02: header-02 -> carousel-03 -> productlist-02 -> promotion-01 -> productlist-03 -> footer-02`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-02` | `<header-02>` | Sticky navigation header with promotional announcement bar, search bar, category shortcuts, and cart indicators |
| `Carousel-03` | `<carousel-03>` | Hero responsive full-width promotional banner carousel with touch swipe and autoplay |
| `ProductList-02` | `<productlist-02>` | Featured bestseller products grid showcase with add-to-cart actions |
| `Promotion-01` | `<promotion-01>` | Visual promotional marketing banner for seasonal sales campaign and highlights |
| `ProductList-03` | `<productlist-03>` | Personalized product recommendation feed showcase |
| `Footer-02` | `<footer-02>` | Global site footer with trust badges, multi-column sitemap navigation, and copyright |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
