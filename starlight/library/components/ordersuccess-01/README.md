# OrderSuccess-01

订单支付成功与凭据确认页面，包含绿色成功勾选图标骨架、订单编号与金额横幅、预计送达时间、收货人配送摘要与继续购物引导按钮。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 居中单栏卡片布局，外层使用 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），最大宽度 680px 居中排版。
- 移动端：宽度 calc(100vw - 32px)，按键垂直排列便于单手触控。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `orderId` | 订单编号文本 | `string` | `'ORD-2026-9988'` |

### 事件机制
- `order-navigate`: 点击查看订单或继续购物时派发页面跳转事件。
