# ProductList-03

电商核心热门商品轮播展示板块，集成居中大标题骨架占位、Swiper 轮播轨道及多断点响应式商品卡片展示，左右切换箭头使用绝对定位悬浮于轮播之上，不占用外层额外宽度。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。

### 尺寸与响应式
- 外层容器严格遵循 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），PC 最大内容宽度 1200px 居中对齐。
- 轮播导航箭头绝对定位悬浮于轮播轨道两侧上方，不额外占用内容宽度。
- 桌面端（1024px+）：5 列轮播展示，间距 24px。
- 平板端（768px~1023px）：4 列轮播展示，间隙 20px。
- 移动端（小于 768px）：自适应为 2~3 列紧凑轮播，卡片自适应拉平。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `containerId` | 商品挂载容器选择器 ID | `string` | `'product-slider-03'` |
| `limit` | 轮播渲染商品数量 | `number` | `8` |

### 事件机制
- `product-navigate`: 点击单张商品卡片时冒泡派发商品跳转事件。
