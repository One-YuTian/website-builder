# Header-08

左对齐紧凑型单通栏电商导航栏组件，标志与导航项紧密相连，右侧排布操作与用户入口。

## 区域划分
- `logo`: 品牌标志展示区域。
- `desktop-nav`: 紧随标志的主导航链接区域。
- `auth`: 用户登录状态与个人面板区域。
- `mobile-drawer`: 移动端侧滑抽屉菜单区域。

## 尺寸与响应式
- 桌面端：单栏通栏高度约 56px，导航居左排列。
- 移动端：导航折叠为汉堡菜单，保留右侧快捷操作入口。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `is-logged-in` | 用户登录状态标记 | `boolean` | `false` |
| `cart-count` | 购物车徽标商品数量 | `number` | `0` |
| `wishlist-count` | 收藏夹徽标商品数量 | `number` | `0` |
| `theme` | 主题反转模式（深色/浅色） | `string` | `'dark'` |

## 事件机制
- `header-navigate`: 导航栏链接点击与操作跳转事件。

## 独立使用说明
组件作为独立 WebComponent 引入，支持动态切换主题与登录状态。
