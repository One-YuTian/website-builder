## Overview

FlashCard-01 product-card component variant. Regions and interactions are annotated directly within the code implementation via English comments.

### Dimensions & Responsiveness

Retains the actual render image-container aspect ratio, Grid/List branches, widths and Tailwind breakpoints.

### Attributes & Operations

- Actual observedAttributes: `product-id`, `discounted`, `sold-percent`. product-id defaults to `product-01`.
- Implemented actions: see event binding.
- Component events: see source event handling.

### JavaScript

```javascript
class FlashCard extends HTMLElement {
  static observedAttributes = ['product-id', 'discounted', 'sold-percent'];

  constructor() {
    super();
  }

  get productId() { return this.getAttribute('product-id') || 'product-01'; }
  set productId(val) { this.setAttribute('product-id', String(val)); }

  connectedCallback() {
    this.classList.add('block', 'h-full', 'w-full', 'min-w-0');
    this.render();
    this.addEventListener('click', () => {
      this.dispatchEvent(new CustomEvent('product-navigate', {
        detail: { productId: this.productId },
        bubbles: true,
        composed: true
      }));
    });
  }

  render() {
    this.innerHTML = `<article class="flex flex-col h-full bg-surface rounded-xl border border-outline/30 shadow-2xs hover:shadow-sm transition-all overflow-hidden p-2.5 sm:p-3 cursor-pointer select-none group font-sans">
  <div class="relative w-full aspect-square bg-accent/40 rounded-lg flex items-center justify-center overflow-hidden mb-2.5">
    <span class="relative block aspect-[6/5] w-1/2 overflow-hidden rounded-sm border border-muted">
      <span class="absolute right-[15%] top-[15%] size-1/5 rounded-full bg-muted"></span>
      <span class="absolute -bottom-1/4 left-[5%] size-3/4 rotate-45 border-l border-t border-muted"></span>
      <span class="absolute -bottom-1/4 right-0 size-1/2 rotate-45 border-l border-t border-muted"></span>
    </span>
    <span class="absolute top-2 left-2 bg-primary text-white text-[10px] sm:text-xs font-bold px-2 py-0.5 rounded-sm shadow-xs">-40%</span>
  </div>
  <div class="flex flex-col flex-1 justify-between gap-2 p-1">
    <div class="flex items-baseline gap-2">
      <div class="h-4.5 w-16 bg-primary font-bold rounded-xs"></div>
      <div class="h-3.5 w-10 bg-muted/50 rounded-xs line-through"></div>
    </div>
    <div class="mt-auto pt-1">
      <div class="flex justify-between items-center text-[10px] sm:text-xs text-muted mb-1 font-mono">
        <span class="h-2.5 w-8 bg-muted/40 rounded-xs"></span>
        <span class="text-content/70 font-medium">65%</span>
      </div>
      <div class="w-full bg-accent rounded-full h-1.5 sm:h-2 overflow-hidden">
        <div class="bg-primary h-full rounded-full w-[65%]"></div>
      </div>
    </div>
  </div>
</article>`;
  }
}

if (!customElements.get('flashcard-01')) {
  customElements.define('flashcard-01', FlashCard);
}
```
