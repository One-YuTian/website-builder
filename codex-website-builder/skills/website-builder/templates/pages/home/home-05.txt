## Overview

Vibrant lifestyle and trendy department marketplace homepage assembled from modern navigation header, hero carousel, circular category icons, promotional campaign banner, featured product feed, and footer.

### Component Chain
`home-05: header-05 -> carousel-01 -> categories-01 -> promotion-01 -> productlist-01 -> footer-01`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-05` | `<header-05>` | Modern marketplace navigation header with search bar and category menu |
| `Carousel-01` | `<carousel-01>` | Hero responsive banner carousel with touch swipe |
| `Categories-01` | `<categories-01>` | Circular icon-based category navigation block for rapid department navigation |
| `Promotion-01` | `<promotion-01>` | Category-specific promotional banner showcasing thematic deals |
| `ProductList-01` | `<productlist-01>` | Curated products grid showcase with add-to-cart actions |
| `Footer-01` | `<footer-01>` | Global site footer with sitemap links and newsletter signup |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
