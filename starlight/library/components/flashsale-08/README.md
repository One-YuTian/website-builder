# FlashSale-08

限时秒杀专区营销板块，包含倒计时时钟骨架、专区状态标牌、专属折扣商品卡片（内嵌抢购进度条与库存告急角标）以及全部秒杀商品入口。

### 强制规范要求
- **商品卡片组件必须使用 `FlashCard` (`<flashcard-01>`)**：本秒杀/闪购板块的轮播卡片项必须使用专属秒杀卡片组件 `flashcard-01`，该组件内置了限时秒杀价格、折扣角标及库存售罄进度条，严禁用普通通用 Card（如 `card-01`）替代。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 外层容器严格遵循 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），PC 最大内容宽度 1200px 居中对齐。
- 桌面端（1024px+）：展示 3~4 列秒杀商品卡片。
- 移动端（小于 768px）：单行双列展示，超出视口宽度通过横向滑动手势无缝浏览。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `limit` | 秒杀商品展示数量上限 | `number` | `4` |
| `endTime` | 倒计时截止时间戳 | `string` | `'2026-12-31'` |

### 事件机制
- `flashsale-navigate`: 点击查看更多秒杀商品时派发导航事件。
- `product-navigate`: 点击秒杀卡片时派发单品跳转事件，携带商品标识。
