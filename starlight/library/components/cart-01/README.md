# Cart-01

电商全站标准购物车抽屉与组件，支持商品条目列表流式展示、数量增减步进器、单项移除、小计/运费/优惠券核算与前往结账 CTA。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 抽屉模式：在桌面端与移动端均采用右侧滑出抽屉，固定宽度 380px~420px，高度贴合 100dvh。
- 页面嵌入模式：遵循 Tailwind 居中容器（w-full max-w-content mx-auto px-4 lg:px-6），展示宽度 768px~960px。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `itemCount` | 购物车商品总行数 | `number` | `2` |

### 事件机制
- `cart-checkout`: 点击前往结账按钮时派发结账路由事件。
- `cart-update`: 修改商品数量或移除商品时派发购物车更新事件。
