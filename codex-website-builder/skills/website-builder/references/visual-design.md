# 整站视觉设计与验收

Agent 是整站设计负责人。先作设计决策，再复用适合的组件；模板复用指导与整站视觉质量共同指导创作，页面 ready 不使用相似度评分。用户已有品牌规范或指定布局时优先遵守，已有站点局部修改沿用其视觉系统。

## 先定系统，再挑模板

根据品牌定位、目标人群、商品图片和信息密度确定一个明确方向，例如克制的精品零售、清晰的专业设备或温暖的手作品牌。这些只是方向示例，不固定行业配色。把决定随首批源码一起保存为 `website-builder.design.json`：视觉方向与理由、语义色板、亮暗策略、各类页面宽度/边距、字体/字阶、间距/圆角、图片裁剪策略、页面板块与模板对应、购物车采用独立页还是抽屉。保持简短，复用后不重复读取或另起多套配置；实际主题唯一入口仍为 app.js 顶部 Tailwind config。

- **配色**：主色用于品牌识别，辅色服务层次，中性色承载正文和大面积底色，强调色集中于主要行动。协调色温、明度和饱和度，并给 surface/content/muted/outline/primary/on-* 定义成对可读的 token。促销/成功/错误等语义色不能抢走主体。不要从不同模板继承多套红、蓝、阴影和圆角，也不要把彩色渐变、金色或大阴影直接等同于高级。
- **亮暗**：模板提供的是能力，不是全开要求。选择整站明亮、整站深色，或有目的的局部反色（例如深色页头配浅色商品区），并说明原因。局部反色同时处理底色、正文、辅助文字、边框、按钮和 hover/focus，不能只改背景，也不能让一个全局 surface token 使其他板块意外反色。使用共享 Tailwind 色彩 token 和一致的 class；未被选择的主题是备选，不额外渲染成重复区块。只有用户需要时才做主题切换。
- **宽度**：根据商品数量、卡片可读性、图片比例和视觉节奏决定内容宽度，不能机械采用默认1200/1280，也不能一律铺满。页头、主货架与页脚使用协调的容器轴线；全幅横幅允许出血，内部文案仍对齐内容轴。商店可宽、正文宜窄、登录/结账表单有独立舒适宽度；这些差异要有明确用途。content/reading/form 等角色通过唯一 Tailwind config 的 maxWidth 与 utility 表达，不各页硬编码一套容器。插件画布的 iframe 宽度代表预览设备，不能用它代替网站自己的内容宽度设计。
- **层级与节奏**：全站统一标题/正文/辅助字阶、按钮高度、输入框、圆角、边框和间距尺度。每屏有明确主次，主 CTA 清晰；控制标题行长、货架密度和板块数量，避免连续同构横幅、满屏同权卡片、过大空洞或密集促销。留白服务内容，不机械重复模板的演示间隔。
- **图片与细节**：选图的色调、主体位置和清晰度要相容；商品图保持统一画幅/裁剪，品牌图服务叙事。先用真实文案和真实商品检查排版，不靠骨架制造整齐。图标使用一致体系，边框、阴影与动效克制，重要文本不能靠低对比度显得精致。

## 模板选择与80%约束的关系

select 返回候选而非审美决定；不随机决定主题、宽度、板块顺序，也不为了避开 -01 而选不适合的组件。比较候选摘要，只读取本轮确定的模板及必要备选，组合结构/密度/图片比例相容的页头、横幅、卡片与页脚。不是每个分类都必须出现在首页。

先选定布局及亮暗策略，再保持所选模板的核心结构与响应式能力。主题色、字体、全局 maxWidth、圆角与品牌内容由 Agent 统一配置，不要求保留演示默认值；页面整体顺序、板块组合和不同页面的内容宽度由设计目的决定。选定模板后不臆造模板外结构，缺少所需布局时重新选型；保真只作SKILL要求，不设运行时门槛。需要大幅改变组件结构时，先考虑换更适合的模板，必要时更新来源记录。不能为追求结构相似而保留失衡布局、冲突色板或不合适的容器。

## 独立的视觉验收

使用浏览器渲染真实页面，在375/768/1280px检查首页、商品列表、详情和至少一种表单/正文页；额外选用更宽布局时补查该宽度。并排比较代表页，核对：

1. 页头、内容和页脚轴线协调，页面宽度符合内容用途，卡片和表单易读，无横向溢出。
2. 色板、亮暗过渡、字阶、按钮、图标、圆角和间距属于同一系统；文字与控件各状态清晰可辨。
3. 主视觉、主CTA、价格与商品图片有合理层级；真实长标题、价格和缺图/空状态不破坏布局。
4. 移动端重新安排密度和交互，保留已选布局的响应式规则；没有为了缩小截图而挤压桌面布局。

发现不协调先修复共享 token、容器或模板选型，再复查受影响页面。模板还原度只在 SKILL 中指导复用，不执行自动打分；审美需实际渲染判断，不能输出虚构的“高级感得分”或声称自动保证美观。未进行浏览器验证时如实说明。

## demo5迭代的视觉细则

按SKILL中的细则检查：页面/板块底色与商品卡片必须有清晰色差；图标保持单色且背景统一，不给原来无图标的文案加装饰；不增设模板外支付Logo、社交矩阵或外链；不编造数据或商业承诺。保留圆形按钮，其他按钮/卡片采用统一直角或小圆角，不擅自添加模板外阴影或hover描边。同页各板块用统一版心和左右边距；同一货架卡片等高、标题line-clamp-2，面包屑单行truncate。固定示例配色不作为默认方案。
