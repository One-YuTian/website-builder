# Home-11

品牌特卖与高频秒杀综合商城首页，由科技双层导航、大幅活动轮播、大牌特卖专场通栏、阶梯秒杀专区、热销瀑布流及页脚组合而成。

### 组合链路
`home-11：header-03->carousel-03->promotion-05->flashsale-03->productlist-01->footer-01`

### 使用的组件 (Included Components)
- `Header-03` (`<header-03>`): 双层综合吸顶导航栏，含搜索框、多品类导航与购物车。
- `Carousel-03` (`<carousel-03>`): 首屏大幅品牌联合大促轮播海报。
- `Promotion-05` (`<promotion-05>`): 大牌特卖组合促销模块，展示精选合作品牌优惠。
- `FlashSale-03` (`<flashsale-03>`): 超值限时秒杀专场，带倒计时与特惠专区。
- `ProductList-01` (`<productlist-01>`): 综合热门好物推荐商品网格。
- `Footer-01` (`<footer-01>`): 全局站点综合页脚与订阅中心。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
