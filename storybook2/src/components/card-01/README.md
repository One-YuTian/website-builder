# Card-01

标准电商商品卡片组件，基于原生 Web Component 构建。支持 1:1 正方形主图骨架、折扣原价标签、2 行截断商品标题骨架、价格对比与加购/心愿单交互，具备网格（Grid）与列表（List）双展示模式。

### 区域划分与内容说明
- `image-area`: **商品主画幅展示区**，固定 1:1 正方形高宽比（列表模式下固定为 140px~180px 缩略图），内嵌包含山峰与太阳中性图片符号的灰色背景占位骨架；悬浮时具备轻微平滑放大动效。
- `badge-layer`: **促销折扣与特惠角标区**，绝对定位在主图左上角，展示亮色背景的百分比折扣徽标（如 `-20%`、`SALE`）或热销状态标签。
- `title-area`: **商品标题文本区**，严格限制 2 行截断（line-clamp-2）的商品名称文本骨架，点击支持冒泡派发商品跳转事件。
- `rating-area`: **商品评价与口碑区**，水平排列 5 颗黄色/浅灰色星星骨架，以及右侧展示评价数量（如 `(128)`）的小号文本骨架。
- `price-box`: **价格与优惠对比区**，左侧展示高对比度、主色加粗的现价文本骨架，右侧展示带有横向中划线（strikethrough）的浅灰色划线原价文本骨架。
- `action-buttons`: **快速交易与互动按钮区**，包含主图右上角心愿单爱心收藏按钮，以及卡片底部的快速加入购物车（Add to Cart）按钮。

### 尺寸与响应式
- 网格模式（grid）：正方形 1:1 图片比例，卡片由所在容器列等比分配撑满，单卡最大宽度 384px。
- 列表模式（list）：横向左右双栏排版，左侧固定 140px 缩略图，右侧信息自适应拉伸，单卡最大宽度 768px。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `product-id` | 商品唯一标识符 | `string` | `'product-01'` |
| `view-mode` | 排版模式（`'grid'` 网格或 `'list'` 列表） | `string` | `'grid'` |
| `discounted` | 是否展示划线原价对比与折扣浮标 | `boolean` | `false` |

### 事件机制
- `product-navigate`: 点击卡片主图或标题区域时冒泡派发商品详情跳转事件，携带商品唯一标识。
- `card-cart`: 点击快速加入购物车按钮时派发加购事件。
- `card-wishlist`: 点击心愿单爱心按钮时派发收藏状态切换事件。
