## Overview

E-commerce category navigation and product matrix showcase block, featuring circular/square category icon placeholders, category titles, item count tags, and hover transition feedback to guide catalog exploration.

### Layout & Regions
- `block-header`: Section title skeleton and View All Categories link.
- `category-grid`: Responsive multi-column grid or smooth horizontal swipe container for category cards.
- `category-card`: Individual category card with circular/square icon skeleton, title, and count tag.

### Dimensions & Responsiveness
- Follows global design system, outer container uses `content-container` with PC max content width 1200px centered.
- Desktop (1024px+): 6~8 columns equal-width grid display.
- Mobile (under 1024px): Adapts to 2~3 compact grid columns or horizontal scrollable list.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `columns` | Grid column count configuration | `number` | `6` |

### Events
- `category-navigate`: Dispatched when clicking a category card.
