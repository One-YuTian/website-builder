## Overview

Limited-time flash sale and clearance showcase block, integrating countdown timer (hours/minutes/seconds), flash sale title, Shop More CTA, and responsive product card list.

### Layout & Regions
- `sale-header`: Flash sale title skeleton, countdown clock badges, and right-aligned View More link.
- `sale-grid`: Multi-card grid or Swiper slider container.
- `sale-card`: FlashCard product card embedding discount badge, price comparison, and progress bar.

### Dimensions & Responsiveness
- Follows global design system, outer container uses `content-container` with PC max content width 1200px centered.
- Desktop (1024px+): 4~5 cards per row, height 360px~420px.
- Mobile (under 768px): 2 cards per row, horizontally scrollable.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `end-time` | Countdown target timestamp | `string` | `'2026-12-31T23:59:59'` |

### Events
- `flashsale-navigate`: Dispatched when clicking flash sale section or products.

$(function() {

      spaceBetween: 12,
      navigation: {
        nextEl: '.flash-sale-next-07',
        prevEl: '.flash-sale-prev-07'
      },
      breakpoints: {
        640: { slidesPerView: 2.5, spaceBetween: 14 },
        768: { slidesPerView: 3, spaceBetween: 16 },

      }
    });
  }
