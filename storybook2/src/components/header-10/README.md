# Header-10

极简通栏电商导航栏组件，居左排布标志、居中展开分类链接、右侧聚合用户与购物车入口。

## 区域划分
- `logo`: 品牌标志展示区域。
- `desktop-nav`: 居中主导航栏目区域。
- `auth`: 用户个人状态与登录控制区域。
- `mobile-drawer`: 移动端侧滑全功能抽屉区域。

## 尺寸与响应式
- 桌面端：单栏通栏高度约 56px，多区域居中平衡分布。
- 移动端：导航链接收拢为折叠抽屉，保留核心右侧交互。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `is-logged-in` | 用户登录状态标记 | `boolean` | `false` |
| `cart-count` | 购物车徽标商品数量 | `number` | `0` |
| `wishlist-count` | 收藏夹徽标商品数量 | `number` | `0` |
| `theme` | 主题反转模式（深色/浅色） | `string` | `'dark'` |

## 事件机制
- `header-navigate`: 导航栏菜单与操作跳转事件。

## 独立使用说明
组件作为独立 WebComponent 标签引入，支持多端自适应与色彩反转。
