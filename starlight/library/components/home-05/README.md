# Home-05

潮流年轻态百货集市首页，由现代集市导航、首屏轮播、圆形分类金刚区、品类活动通栏、精选瀑布流及页脚组合而成。

### 组合链路
`home-05：header-05->carousel-01->categories-01->promotion-01->productlist-01->footer-01`

### 使用的组件 (Included Components)
- `Header-05` (`<header-05>`): 现代潮流集市导航栏，集成搜索、品类菜单与用户交互区。
- `Carousel-01` (`<carousel-01>`): 首屏活动轮播横幅，支持响应式多屏适配与平滑滑动。
- `Categories-01` (`<categories-01>`): 多品类圆形图标金刚区入口，提供快速品类直达体验。
- `Promotion-01` (`<promotion-01>`): 品类特色营销活动横幅，展示当前主推主题。
- `ProductList-01` (`<productlist-01>`): 为你精选综合商品陈列瀑布流。
- `Footer-01` (`<footer-01>`): 全局底部矩阵与邮件订阅专区。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
