## Overview

User registration and account creation page, containing full name, email, password strength meter, confirm password, terms agreement checkbox, and sign in link.

### Regions
Functional regions are annotated directly in the component code implementation via English comments.


### Dimensions & Responsiveness
- Centered card max width 480px, vertically centered on screen.
- Mobile: Width calc(100vw - 32px) with comfortable touch targets.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `title` | Registration headline | `string` | `'Create Account'` |

### Events
- `auth-register`: Dispatched when submitting registration form.
- `auth-navigate`: Dispatched when clicking sign-in link.

### JavaScript

```javascript
$(function() {
  const $form = $('#register-form');
  if (!$form.length) return;

  $form.on('submit', function(e) {
    e.preventDefault();
    $(this).trigger('register-submit');
  });

  $('[data-action="toggle-pwd"]').on('click', function(e) {
    e.preventDefault();
    const $input = $(this).siblings('input');
    const isPwd = $input.attr('type') === 'password';
    $input.attr('type', isPwd ? 'text' : 'password');
  });

  $('[data-action="goto-login"]').on('click', function(e) {
    e.preventDefault();
    $(this).trigger('auth-navigate', { target: 'login' });
  });
});
```
