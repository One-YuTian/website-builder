# Home-19

东南亚数码科技与电脑办公商城首页，由科技双层导航、新品发布轮播、电脑办公爆款网格、数码周边特惠秒杀、综合数码瀑布流及保障页脚组合而成。

### 组合链路
`home-19：header-03->carousel-01->productlist-02->flashsale-07->productlist-01->footer-02`

### 使用的组件 (Included Components)
- `Header-03` (`<header-03>`): 科技商城双层吸顶导航，含多层级数码分类与检索。
- `Carousel-01` (`<carousel-01>`): 科技数码首屏发布轮播横幅。
- `ProductList-02` (`<productlist-02>`): 电脑整机、平板与办公数码畅销榜网格。
- `FlashSale-07` (`<flashsale-07>`): 数码周边与极客配件限时特惠秒杀专区。
- `ProductList-01` (`<productlist-01>`): 综合消费类数码商品精选陈列列表。
- `Footer-02` (`<footer-02>`): 数码售后保修与正品保障页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
