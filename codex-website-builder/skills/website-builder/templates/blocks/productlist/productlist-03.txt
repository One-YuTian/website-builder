## Overview

Core e-commerce catalog shelf block, integrating section title, quick category filter tags, 4~5 column responsive product card matrix, and bottom View All Products action.

### Layout & Regions
- `block-header`: Main title skeleton and category filter pills.
- `product-grid`: Multi-column product card matrix container.
- `product-card`: Standard Card component instances.
- `block-footer`: Bottom View All Products button.

### Dimensions & Responsiveness
- Follows global design system, outer container uses `content-container` with PC max content width 1200px centered.
- Desktop (1024px+): 4~5 columns equal-width grid with 20px gap.
- Mobile (under 768px): 2 compact columns with 12px gap.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `columns` | Grid column count | `number` | `4` |

### Events
- `productlist-filter`: Dispatched when switching category filter pills.
- `productlist-more`: Dispatched when clicking View All Products.

### JavaScript

```javascript
$(function() {
  const $container = $('#product-slider-03');
  if ($container.length) {
    const products = [
      { id: 'product-01', discounted: true },
      { id: 'product-02', discounted: false },
      { id: 'product-03', discounted: true },
      { id: 'product-04', discounted: false },
      { id: 'product-05', discounted: true },
      { id: 'product-06', discounted: false },
      { id: 'product-07', discounted: true },
      { id: 'product-08', discounted: false }
    ];

    $container.empty();
    for (let i = 0; i < products.length; i++) {
      const p = products[i];
      const $slide = $('<div class="swiper-slide"></div>');
      const $card = $('<card-01></card-01>').attr('product-id', p.id);
      if (p.discounted) {
        $card.attr('discounted', '');
      }
      $slide.append($card);
      $container.append($slide);
    }
  }

  if (typeof Swiper !== 'undefined' && $('.popular-products-swiper').length) {
    new Swiper('.popular-products-swiper', {
      slidesPerView: 2,
      spaceBetween: 12,
      loop: true,
      navigation: {
        nextEl: '.swiper-button-next',
        prevEl: '.swiper-button-prev'
      },
      breakpoints: {
        640: {
          slidesPerView: 3,
          spaceBetween: 16
        },
        768: {
          slidesPerView: 4,
          spaceBetween: 20
        },
        1024: {
          slidesPerView: 5,
          spaceBetween: 24
        }
      }
    });
  }
});
```
