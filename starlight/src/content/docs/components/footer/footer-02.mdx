## Overview

Standard e-commerce site footer component, integrating brand LOGO skeleton, corporate mission statement, multi-column category navigation matrix, social media icons, security trust badges, and copyright/compliance bar with adaptive responsive grid layout.

### Layout & Detailed Region Breakdown
- `brand-section`: **Brand mission and company region**, located at first column on the left, containing brand `LOGO` skeleton, 2~3 lines of corporate mission description skeleton, and 4 circular social media icon skeletons (Facebook, Instagram, Twitter, YouTube).
- `nav-columns`: **Multi-column structured navigation matrix region**, containing 3~4 equal-width vertical lists (Shopping Guide, Customer Care, About Us, Policies & Compliance), each with bold column title skeleton and 4~5 sub-page link skeletons.
- `newsletter-box`: **Email newsletter subscription region**, containing single-line email input skeleton and Subscribe CTA button for customer lead capture.
- `bottom-bar`: **Copyright and trust badge bottom bar**, separated by top border line, containing left-aligned copyright year and license registration skeleton, and right-aligned payment badges (Visa, Mastercard, PayPal).

### Dimensions & Responsiveness
- Follows global design system, outer container uses `content-container` with PC max content width 1200px centered.
- Desktop (1024px+): 3 to 4 column grid layout side by side with 32px~48px gutter spacing.
- Mobile (under 1024px): Adapts to single-column vertical flow with generous spacing between columns, ensuring touch targets are at least 44px high.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `columns` | Number of columns in main footer layout | `number` | `3` |

### Events
- `footer-navigate`: Dispatched when user clicks any footer navigation link or social icon.
