# Promotion-01

商业促销横幅与活动展示板块，左侧为大图营销横幅，右侧为 4 列促销商品网格矩阵。

### 强制规范要求
1. **右侧商品图规范**：每张商品促销卡片图片区域必须使用 1:1 比例（`aspect-square`），纯色浅色背景垫底（`bg-accent/40`），图片本身使用 `object-cover` 撑满比例并居中裁剪。
2. **底部文案固定高度与超出省略**：底部文案区域必须使用固定高度容器（`h-8` 容器结合 `line-clamp-2 overflow-hidden text-ellipsis`），超出文本必须截断显示省略号，以保证多张促销卡片高度严格齐平对齐，避免因标题行数不一造成网格对齐断层。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 遵循全局设计规范，外层容器使用 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），最大宽度 1200px 居中排版。
- 桌面端（1024px+）：2~3 栏拼贴布局，卡片高度 240px~360px。
- 移动端（小于 768px）：单栏垂直层叠流动排布。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `columns` | 并排促销展板列数 | `number` | `2` |

### 事件机制
- `promo-navigate`: 点击单张促销横幅或行动按钮时派发跳转事件。
