## Overview

Contemporary interior and home living homepage assembled from promo sticky navigation header, premium home comfort carousel, modern minimalist furniture showcase, home design renovation banner, interior decor & lighting grid, and footer.

### Component Chain
`home-26: header-04 -> carousel-03 -> productlist-02 -> promotion-09 -> productlist-03 -> footer-02`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-04` | `<header-04>` | Promo-focused sticky navigation bar with countdown announcement |
| `Carousel-03` | `<carousel-03>` | Hero responsive full-width banner carousel for seasonal furniture collections |
| `ProductList-02` | `<productlist-02>` | Modern minimalist furniture showcase bestseller products grid |
| `Promotion-09` | `<promotion-09>` | Whole-home customization and living room design promotional banner |
| `ProductList-03` | `<productlist-03>` | Interior decor, designer lighting, and textile goods collection grid |
| `Footer-02` | `<footer-02>` | Modern home living warranty, customer support, and trusted footer |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
