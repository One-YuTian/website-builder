# Detail-01

标准五列双区电商商品详情页面组件，包含左侧吸顶多图画廊与右侧购买面板、规格选择及服务保障。

## 区域划分
- `breadcrumb`: 顶部层级面包屑导航区域。
- `gallery`: 桌面端占 2 列的商品主图与下方多张缩略图切换区域。
- `info`: 桌面端占 3 列的商品标题、星级评价、价格行、数量步进器与购买按钮区域。
- `tabs`: 包含规格参数与用户评价切换展示的选项卡区域。
- `related-products`: 底部 4 列相关商品推荐卡片区域。

## 尺寸与响应式
- 页面容器：由全局 `content-container` 控制内容最大宽度。
- 详情主结构：移动端单列垂直堆叠，桌面端 `lg` 视口展开为 5 列布局（2 列画廊 + 3 列信息），画廊支持吸顶停靠（`sticky top-24`）。
- 缩略图：固定宽高 64px 至 80px 圆角方形。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `productId` | 关联商品唯一编号 | `string` | `'product-01'` |

## 事件机制
- `product-navigate`: 点击加购或购买按钮时冒泡派发的商品交互事件。

## 独立使用说明
作为独立页面级模板使用，直接渲染基础 HTML 结构并通过内置脚本驱动画廊与数量交互。
