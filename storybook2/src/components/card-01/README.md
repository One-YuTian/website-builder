# Card-01

Versatile product card supporting grid and list display modes, complete with product image, multi-line title, ratings, and price badge.

## Attributes

| Attribute | Property | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `product-id` | `productId` | string | `'product-01'` | Unique identifier associated with the product card. |
| `view-mode` | `viewMode` | `'grid' \| 'list'` | `'grid'` | Layout mode for card presentation. |
| `discounted` | `discounted` | boolean | `false` | Displays discount badge and original price when present. |
