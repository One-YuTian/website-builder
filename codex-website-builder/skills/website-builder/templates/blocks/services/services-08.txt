## Overview

Trust endorsement and customer service value proposition block, integrating authentic guarantee, free shipping, secure payment, and easy returns presented as horizontal feature cards.

### Layout & Regions
- `services-container`: Service card grid container.
- `service-item`: Individual service item with circular icon skeleton, bold title, and description.

### Dimensions & Responsiveness
- Follows global design system, outer container uses `content-container` with PC max content width 1200px centered.
- Desktop (1024px+): 3~4 equal-width columns in a single row without wrapping.
- Mobile (under 1024px): Adapts to 2x2 grid or smooth horizontal scroll.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `columns` | Column count configuration | `number` | `4` |

### Events
- `service-navigate`: Dispatched when clicking a service guarantee item.
