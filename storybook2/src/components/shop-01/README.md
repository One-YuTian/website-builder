# Shop-01

标准商城商品列表页面组件，包含页面标题区、价格排序与商品计数工具栏、响应式四列商品网格。

## 区域划分
- `page-header`: 顶部商城标题与副标题描述区域。
- `toolbar`: 价格排序下拉选择框与统计数量区域。
- `products-grid`: 2 列（小屏）至 4 列（大屏）商品卡片网格容器区域。

## 尺寸与响应式
- 页面容器：由全局 `content-container` 控制内容最大宽度与居中内边距。
- 商品网格：移动端单行 2 列，平板视口 3 列，桌面端 `lg` 视口展开为 4 列，间距自适应 16px 至 24px。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `sortOrder` | 价格排序规则（`default` / `asc` / `desc`） | `string` | `'default'` |

## 事件机制
- `product-navigate`: 子级商品卡片点击时冒泡派发的商品交互事件。

## 独立使用说明
作为独立页面级模板使用，直接渲染基础 HTML 结构并通过内置脚本驱动卡片与排序交互。
