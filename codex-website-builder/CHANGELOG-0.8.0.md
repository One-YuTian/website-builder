# 0.8.0

- 首页采用毛玻璃项目列表与输入面板，项目按“网站-域名”及年月日时间展示，列表顶部对齐、紧凑间距、隐藏滚动条；连续固定白色渐变消除列表旁的明暗断层。
- 详情页顶部按图片文件名展示项目图片，保留透明背景，以独立比例和320–960px宽度从左上角排列；支持原尺寸PNG复制及其他格式转PNG复制。
- 页面支持复制当前状态的完整截图，等待图片、字体和动态内容完成；保留表单与展开状态，通过分片传输避免单页消息大小限制。
- “查看全部”按实际内容宽度自适应，优先横向铺满并避开工具栏，长内容从顶部展示、通过平移查看；重复操作不产生缩放漂移。
- 修复Windows打开项目目录的结果判断，优先恢复并激活已有对应目录窗口；保留macOS与Linux目录打开实现。
- 面板和页面预览禁用文本选择与右键菜单，预览适配不修改网站源文件。
- 延续Codex内置Node启动、预构建运行包、SQLite项目管理与增量预览。

发布目标：仓库beta分支。Windows已完成自动化验证；本次没有macOS实机验证。
