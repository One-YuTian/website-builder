# Header-02

Sticky header featuring a top utility promotion bar, gradient background, right-aligned search bar, and full responsive support with a mobile drawer.

## Attributes

| Attribute | Property | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `is-logged-in` | `isLoggedIn` | boolean | `false` | Displays authenticated navigation items when present. |
| `cart-count` | `cartCount` | number | `0` | Item count badge for the cart action icon. |
| `wishlist-count` | `wishlistCount` | number | `0` | Item count badge for the wishlist action icon. |
