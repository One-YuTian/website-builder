# Detail-04

商品详情页面（PDP），包含多视角画廊预览、购买决策核心区（标题、原价现价、SKU 规格选择器、步进器、加购/购买按键）及底部手风琴折叠面板。

### 区域划分与内容说明
- `gallery`: **左侧多视角图片画廊区**，包含大画幅商品主图预览视窗（支持鼠标悬浮放大或多图轮播），以及下方或左侧的 4~5 张缩略图列表骨架。
- `summary`: **右侧购买决策核心区**：包含商品标题与品牌标签、5 星评分与评价数、现价高亮与划线原价对比、SKU 颜色色块选择组、尺码大小方块选择器、数量步进器（- 1 +）、加购与立即购买双行动按钮，以及免运费退换货条款徽章。
- `accordion-tabs`: **下方深度信息手风琴折叠面板区**，包含商品详细描述（Description）、规格参数表格（Specifications）、物流配送政策（Shipping & Returns）以及买家评价列表（Reviews）。

### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 `content-container`，PC 最大内容宽度 1200px 居中排版。
- 桌面端（1024px+）：采用 1:1 双栏并排（左侧画廊 550px，右侧购买信息 550px）。
- 移动端（小于 1024px）：双栏自动转为单列垂直排布，画廊支持手势横向滑动，购买按钮贴底对齐。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `productId` | 当前详情展示的商品唯一标识符 | `string` | `'product-01'` |

### 事件机制
- `product-navigate`: 点击关联推荐商品时派发页面跳转事件。
- `gallery-change`: 切换缩略图视点时派发画廊更新事件。
