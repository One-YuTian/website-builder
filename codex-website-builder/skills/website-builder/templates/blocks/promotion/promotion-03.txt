## Overview

Promotional campaign banner section, supporting equal multi-column or asymmetric mosaic layouts with rich background marketing imagery, discount tags, and fast CTAs.

### Regions
Functional regions are annotated directly in the component code implementation via English comments.


### Dimensions & Responsiveness
- Follows Tailwind centered container（`w-full max-w-content mx-auto px-4 lg:px-6`） with max content width 1200px centered.
- Desktop (1024px+): 2~3 column layout with 240px~360px card heights.
- Mobile (under 768px): Single column vertical stacking.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `columns` | Number of promotional banner columns | `number` | `2` |

### Events
- `promo-navigate`: Dispatched when clicking banner card or CTA button.

## Code

### HTML

```html
<section class="bg-accent/40 py-4 font-sans text-content">
  <div class="w-full max-w-content mx-auto px-4 lg:px-6">
    <div role="button" tabindex="0" class="w-full aspect-[4/1] bg-surface rounded-xl border border-outline/30 flex items-center justify-center overflow-hidden cursor-pointer shadow-2xs">
      <span class="relative block aspect-[6/5] w-1/4 max-w-28 overflow-hidden rounded-sm border border-muted">
    <span class="absolute right-[15%] top-[15%] size-1/5 rounded-full bg-muted"></span>
    <span class="absolute -bottom-1/4 left-[5%] size-3/4 rotate-45 border-l border-t border-muted"></span>
    <span class="absolute -bottom-1/4 right-0 size-1/2 rotate-45 border-l border-t border-muted"></span>
  </span>
    </div>
  </div>
</section>
```

### JavaScript

```javascript
$(function() {
  $('section').on('click', '[role="button"]', function(e) {
    e.preventDefault();
    $(this).trigger('promotion-navigate');
  });
});
```
