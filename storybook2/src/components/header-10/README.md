# Header-10

顶部全局粘性导航栏组件，整合品牌 LOGO 骨架、全站级联想搜索框、用户鉴权与个人中心入口、愿望单与购物车计数角标，以及横向类目导航菜单。具备吸顶（Sticky）定位能力与移动端轻量滑出式抽屉导航，支持高内聚独立渲染。

### 区域划分与内容说明
- `logo-area`: **品牌标志区域**，固定高度 40px，内嵌居左带有中性 `LOGO` 标识的圆角骨架矩形；具备全站主路由点击交互，点击后派发 `header-navigate` 事件返回商城首页。
- `search`: **全站预测搜索区域**，采用全圆角或高圆角胶囊容器，包含半透明搜索占位文本骨架、清除按钮以及右侧放大镜检索提交按钮；输入变动时派发 `header-search-input`，并在输入框下方绝对定位弹出最多 6 项带有缩略图骨架与标题文本的智能联想建议列表面板（`search-suggestions`）。
- `navigation`: **桌面端主类目导航菜单区**，在大于 1024px 视口下横向水平排布，包含 4~6 个一级品类导航项骨架（如 Home、Shop、Categories、About、Contact 等）；悬浮时展现微动交互，点击链接派发页面导航事件。
- `account-panel`: **用户鉴权与个人中心区域**，由圆形用户头像图标触发；未登录态点击直接跳转登录页，已登录态悬浮或点击后向下展开下拉操作面板，内含用户名/会员等级骨架、订单管理中心（Orders）入口以及退出登录（Logout）按钮。
- `action-icons`: **快捷操作功能图标组**，位于页头右上角，包含带数字徽标的心愿单收藏图标、带主色圆形计数徽标的购物车抽屉触发图标，以及在小于 1024px 时显现的移动端汉堡包菜单切换按钮。
- `mobile-drawer`: **移动端滑出式抽屉区域**，在小屏设备上从左侧滑出（最大宽度 320px），顶部包含品牌 LOGO 骨架与快速关闭叉号图标，中部以垂直大间距展示全部主导航与分类折叠项，底部包含登录/注册账户操作栏。

### 尺寸与响应式
- 桌面端（1024px+）：高度固定为 68px~76px，遵循全局 `content-container` 最大内容宽度 1200px 居中对齐，支持页面滚动时粘性吸顶。
- 平板与移动端（小于 1024px）：横向分类列表自动折叠隐藏，主栏保留 Logo、搜索入口与操作图标；汉堡包按钮触发 320px 宽度平滑滑出式侧边抽屉。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `theme` | 颜色主题配置，支持深色（dark）与浅色（light）反转切换 | `'dark' \| 'light'` | `'dark'` |
| `is-logged-in` | 登录状态控制，影响用户中心图标态与登录入口呈现 | `boolean` | `false` |
| `cart-count` | 购物车图标右上角数字角标数值 | `number` | `0` |
| `wishlist-count` | 心愿单图标右上角数字角标数值 | `number` | `0` |

### 事件机制
- `header-navigate`: 点击品牌 Logo、主导航链接或个人中心菜单项时派发导航路由事件。
- `header-search`: 提交搜索表单或敲击回车时派发搜索查询事件。
- `header-search-input`: 搜索输入框内容变动时实时派发检索联想事件。
- `header-cart`: 点击购物车操作图标时派发抽屉唤起事件。
