# 0.7.6 批量提交与页面就绪同步

## 修复

- website_write恢复多HTML和共享文件的批量提交。逐页即时落盘约束生成时机，不限制接口文件数量。
- 所有提交HTML和依赖发生变化的页面自动校验；finalize_pages是追加校验目标，空数组不再让页面滞留generating。
- 补齐依赖会重新校验之前未就绪/失败的页面，通过即ready并向UI同步，无需等全部页面生成。
- begin记录原HTML指纹，UI跨进程长轮询检测直接写出的完整新HTML并进行校验；未改动旧HTML和未完成HTML继续隐藏。
- finish省略paths时校验全部未完成页；主SKILL要求结束前收尾并检查状态。
- 格式/语法失败和落盘失败记录error，避免生成中状态无终点。已有有效文件在语法失败时保留。
- UI逐页处理预览解码失败，成功页继续显示，失败页不确认版本并自动重试；新快照重置加载确认状态。
- 移除测试中的单页拆批辅助脚本，恢复真实批量接口回归。

## 验证

TypeScript检查、前后端构建；代码输出、跨进程项目/UI、大图传输、组件、交易、模板等相关回归。项目浏览器回归覆盖：一页完成而其他页仍未生成时显示、批量提交、空finalize_pages、补齐缺失依赖、直接写文件同步、旧页面不误就绪、finish收尾、无关iframe状态保留。

此更新为本地插件源码和构建产物，尚未在已安装Codex插件宿主中重载验证。现有网站及用户参考目录不重写。
