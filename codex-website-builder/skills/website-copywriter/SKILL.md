# 网站文案生成

建站缺少网站文案或用户要求改文案时使用。读取当前 brief、design、页面计划、所选模板槽位与已有内容，确认品牌、国家、语言、币种和业务模式；从现有项目推断缺项，关键国家无法推断时再询问。

生成对应部分：网站及各页 title/SEO description、导航/按钮/表单提示/空状态、页脚版权与介绍、联系页、About Us、隐私政策，以及实际计划中的服务条款/退换货正文。只填现有槽位，不凭空增加区域，不生成商品名称、商品描述、商品价格、折扣、销量或评价。

先统一域名身份：用户给定或当前站点实际域名优先，排除随机项目ID和临时预览域名；www.abcd.com默认品牌abcd、联系邮箱support@abcd.com、版权署名abcd（如© 当前年份 abcd）。Logo可基于品牌作视觉延展。去掉协议、路径、端口、www前缀，按实际主域及多级后缀识别品牌，不机械取倒数第二段。用户明确给定品牌/联系方式/版权时沿用；全站标题、品牌、About Us、Footer、联系及政策一致，不再默认example.com邮箱。

页脚手机号、地址沿用虚构资料规范，并与联系页/政策一致。按目标国家的国际区号、号码分组、地址顺序、邮编形式和语言生成；号码用户部分不得包含3位及以上连续递增/递减数字段（如123、789、987、321），也不能整串重复数字；国际区号按目标国真实规则保留。优先该国保留的示例号码段，不确定时查官方编号资料，不能声称随机号码绝对无人使用。地址不冒用真实企业住址。country、locale、fictional:true及待核实资料只记录到metadata_directory或交付说明；不再在顾客可见页面附加“演示联系信息”等告示。域名邮箱采用上述support规则，不声称邮箱已验证可收信；7×24小时服务等已授权文案按下方政策使用，不因邮箱尚未验证而删除服务板块。

## 正式网站语境（仅提示规范）

网站文案面向顾客，围绕品牌介绍、产品选购、使用场景、联系、账户/交易与必要政策展开，提供具体、自然、有信息量的内容。不得出现“这是演示商店/示例网站”“功能只在本地浏览器运行”“模拟账户/收藏/购物车/订单”“不代表销售、收费或配送”“品牌素材仅为示意”等开发声明，任意语言的同义表达同样不写入页面、SEO、弹窗、Toast或图片；用户指出的葡语告示不能作为默认免责声明。技术实现说明、Mock来源和虚构联系资料标记仅放交付说明/metadata_directory。真实感通过品牌与内容一致性体现，不编造事实、业绩、认证或授权范围之外的服务保证；7×24小时服务、7天无理由退货及货到付款按已授权策略直接使用；隐私政策仍客观说明实际数据处理。注册字段文案覆盖用户名、邮箱、带区号手机号、账号密码、确认密码；加购成功提示简短说明结果，不宣称购物车已自动打开。本节不增加程序校验、扫描或页面ready条件。

## 按场景决定长短

先识别文案承载的位置、用户目标、阅读方式和所选模板容量，再决定长度；不能所有区域都用一句话，也不能为凑字数给短槽位塞长段落。

- 导航、按钮、字段标签、提示和空状态：简短明确，动作与结果可理解；Header保留Home/Shop/About Us/Contact Us四项的本地化名称。
- 网站标题、地址、邮箱、手机号、导航、按钮与字段标签等关键短信息保持清晰简洁；Banner说明、板块介绍、品牌介绍、联系页引导、页脚品牌介绍及其他叙述正文要充分展开，通常以2–4句有意义的完整句子表达背景、细节、使用场景或下一步，不能只用一句泛泛口号概过。Banner说明需按实际槽位用较短句子分段，不为凑句数遮图；Toast、字段错误等即时提示仍保持短而明确。
- About Us：可以充分、详细，分节展开品牌定位、关注的使用场景、产品选择思路、设计理念、与受众的关系及联系途径；每节内容有实际意义，避免重复口号。不编造创始年份、人数、工厂、团队、奖项、认证、业绩或环保成效。
- 隐私政策：可以尽可能完整、详细，结合实际网站实现分节说明适用范围、数据类别与来源、收集用途、账户/购物车/心愿单/订单存储、Cookie或localStorage、实际第三方服务、数据管理/删除渠道及联系信息等；没有实现的收集、共享、功能不能声称存在，未知业务事实列为待提供，不编造留存天数、处理时限或法律合规认证。

About Us与政策正文用清晰标题、自然段和适量列表组织，不用整篇大段文字，也不把正文截断成营销短句；不设机械的总字数，但叙述性内容应有足够细节，不用单句占位；About Us和隐私政策比普通板块更详细、更完整，按阅读结构分节。根据模板与多端空间安排段落，必要时选用更适合丰富正文的相容版式，不用删成一句话来掩盖排版问题。可以选用容纳长正文的相容模板/现有正文槽位，不因此新增模板不存在的营销区域。

## 模板与服务文案

按[文案边界与已授权服务](references/content-policy.md)执行：模板模块均可使用，结构不能因旧版承诺限制被删。7×24小时服务、7天无理由退货、支持货到付款已获明确允许，可直接本地化使用；其余业务事实和额外保证按该文档处理。这一授权优先于本技能中“不编造服务能力或承诺”等通用限制，不把已允许文案再次列为待确认。

## 按需图文协作

About Us等叙事内容有必要配图时，调用同包 [网站图片生成技能](../website-image-generator/SKILL.md)，传入该节主题、图片内容、实际槽位尺寸/比例、主体位置和文字安全区。优先复用合适素材或生成一张可自动裁切的无字主图；确有必要再生成多端版本。文案由HTML承载，图与文字分栏/上下呈现，叠字只使用真实留白，逐端确认文字没有遮住图片主体。政策页以清晰正文为主，不为装饰强行生图。

文案草稿、country/locale/fictional标记和虚构联系信息记录仅保存到生产目录外的metadata_directory/website-builder.copy.json，正式文案写入网站实际页面或共享组件；不得另在生产目录加文案JSON、草稿、数据源或生成脚本，并按需求写入对应页面/共享组件；仍走 begin/write/finish，保留商品数据和模板结构。检查目标语言一致、长度适配、联系方式跨页一致、无商品价格、无超出已授权范围的额外保证及残留占位词。返回修改页面和需真实业务资料补齐的项目。

## 页面行为边界

按钮/表单/Toast文案对应主技能[网站要求](../website-builder/references/site-requirements.md)的真实行为，不在文案技能重复维护注册、登录和结算规则。商品评分、评价、回复与价格只引用已有数据，不编造。
