# Shop-02

商城货架主列表页面，整合页面标题骨架、多维筛选侧边栏、排序工具栏、商品总数统计以及多列商品卡片自适应网格，支持价格升序/降序动态排序交互。

### 区域划分与内容说明
- `page-header`: **页面导读区**，包含全宽页面大标题骨架、面包屑导航（Home > Shop）以及品类背景介绍文案。
- `filter-sidebar`: **左侧综合筛选侧边栏**（PC端并排，移动端转为抽屉），包含价格区间滑动筛选器、多选品牌复选框组、颜色色块筛选器、尺码方块选择器。
- `toolbar`: **商品列表控制工具栏**，包含当前筛选匹配的商品总数统计文本（如 Showing 1-12 of 48 products）、网格/列表排版切换按钮组，以及综合/价格/销量排序下拉选择框。
- `products-grid`: **核心商品结果陈列区**，自适应响应式多列商品卡片矩阵（挂载 Card 组件）。
- `pagination-bar`: **底部翻页分页区**，包含上一页、页码数字按钮序列（1, 2, 3...）、下一页控制按钮。

### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 `content-container`，PC 最大内容宽度 1200px 居中排版。
- 桌面端（1024px+）：4 列等宽商品卡片并排，左侧可配 260px 筛选栏。
- 移动端（小于 768px）：自适应为 2 列紧凑网格，顶部工具栏折行对齐。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `defaultSort` | 默认商品排序规则（`'default'`、`'asc'` 升序、`'desc'` 降序） | `string` | `'default'` |
| `itemCount` | 初始渲染商品数量 | `number` | `8` |

### 事件机制
- `product-navigate`: 点击商品卡片时派发商品跳转事件。
- `shop-sort`: 切换排序规则时触发列表重新渲染事件。
