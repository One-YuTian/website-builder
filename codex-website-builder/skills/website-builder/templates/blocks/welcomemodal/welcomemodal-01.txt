## Overview

New customer welcome and exclusive discount marketing modal popup block, featuring brand badge, dual-layer headline, coupon voucher card, 3-point service benefit list, and CTA buttons.

### Layout & Regions
- `modal-backdrop`: Semi-transparent darkened background overlay.
- `modal-body`: Centered modal dialog with brand badge, title, coupon card, and benefits.
- `close-button`: Top-right close icon button.

### Dimensions & Responsiveness
- Dialog max width 32rem (512px) centered in viewport.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `open` | Modal visibility state | `boolean` | `true` |

### Events
- `welcomemodal-close`: Dispatched when closing the welcome modal.
- `welcomemodal-claim`: Dispatched when claiming the coupon discount.

### JavaScript

```javascript
$(function() {
  $('[data-region="modal-card"]').on('click', '[data-action]', function(e) {
    e.preventDefault();
    const action = $(this).data('action');
    $(this).trigger('welcomemodal-action', { action });
  });
});
```
