# Carousel-03

首页全宽主视觉轮播展示板块，支持多画幅等比缩放、触控拖拽滑动、自动轮播定时器、底部圆点分页指示器与左右切换箭头，桌面端与移动端按断点提供专用画幅适配。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 `content-container`，PC 最大内容宽度 1200px 居中对齐。
- 桌面端（1024px+）：高度固定为 500px~550px，图文浮层保持稳定对齐。
- 移动端（小于 1024px）：自适应收缩为 16:9 或 50:21 高宽比，支持手势横滑平滑翻页。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `stageSelector` | 初始化挂载容器选择器 | `string` | `'#carousel-01-stage'` |
| `interval` | 自动轮播切换时间间隔（毫秒） | `number` | `5000` |
| `paused` | 是否暂停自动播放 | `boolean` | `false` |

### 事件机制
- `carousel-navigate`: 点击轮播幻灯片时派发页面跳转事件。
- `carousel-change`: 轮播切换到新滑块时派发，携带当前活跃索引参数。
