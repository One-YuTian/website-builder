# Card-11

大圆角现代商品卡片组件，具有 1:1 正方形主图、星级评分与醒目右下角圆形加购按钮。

## 区域划分
- `image-area`: 顶部或左侧 1:1 正方形商品主图区域，带大圆角顶框。
- `content-area`: 包含双行商品标题、星级评分与折扣胶囊、双价格及右下角圆形加购按钮区域。

## 尺寸与响应式
- 网格视图：纵向流式自适应父级网格，主图比例为 1:1。
- 列表视图：横向图文排版，大屏主图宽度固定为 192px，左侧边缘带大圆角过渡。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `product-id` | 商品唯一标识 | `string` | `'product-01'` |
| `view-mode` | 排版布局模式（`grid` 或 `list`） | `string` | `'grid'` |
| `discounted` | 折扣状态与原价显示标记 | `boolean` | `false` |

## 事件机制
- `product-navigate`: 点击卡片或圆形加购按钮时派发商品交互事件。

## 独立使用说明
组件作为独立 WebComponent 引入，可直接嵌入网格列表或轮播板块容器中使用。
