# Services-08

电商商城特色服务保障与信任背书板块，通过等宽栅格排布官方正品、免费极速配送、无忧退换货与 24/7 在线客服等核心保障项目。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 遵循全局设计规范，外层容器使用 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），最大宽度 1200px 居中对齐。
- 桌面端（1024px+）：3~4 列等宽网格横向平铺，卡片内含充足留白。
- 移动端（小于 768px）：自适应为单列垂直堆叠或 2 列紧凑网格。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `columns` | 服务卡片列数 | `number` | `4` |

### 事件机制
- `service-click`: 点击服务卡片时派发事件，展示详细政策说明。
