# Home-08

厨卫用品与清洁收纳专门店首页，由垂类实用吸顶导航、洁净好物首屏轮播、高频爆品网格、闪电配送服务条及页脚组合而成。

### 组合链路
`home-08：header-08->carousel-03->productlist-02->services-08->footer-02`

### 使用的组件 (Included Components)
- `Header-08` (`<header-08>`): 厨卫生活垂直分类导航栏，包含品类快捷查找与购物车。
- `Carousel-03` (`<carousel-03>`): 首屏大幅洁净好物活动轮播海报。
- `ProductList-02` (`<productlist-02>`): 厨房清洁高频复购爆品四列网格。
- `Services-08` (`<services-08>`): 闪电配送、环保无害与退换服务权益条。
- `Footer-02` (`<footer-02>`): 专属售后支持与安全支付保障页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
