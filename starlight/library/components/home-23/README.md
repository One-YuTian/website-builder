# Home-23

智能通讯终端与数码硬件垂直首页，由科技双层导航、通讯硬件首屏轮播、终端品类入口、穿戴音频秒杀专区、官方验机服务条、智能设备瀑布流及页脚组合而成。

### 组合链路
`home-23：header-03->carousel-28->categories-07->flashsale-08->services-05->productlist-01->footer-01`

### 使用的组件 (Included Components)
- `Header-03` (`<header-03>`): 智能通讯数码港双层吸顶导航，含多层分类菜单。
- `Carousel-28` (`<carousel-28>`): 移动通讯与智能硬件首屏大幅轮播海报。
- `Categories-07` (`<categories-07>`): 品牌专区与终端类型快速导购卡片。
- `FlashSale-08` (`<flashsale-08>`): 智能手表与真无线降噪耳机限时特惠秒杀。
- `Services-05` (`<services-05>`): 官方正品验机报告、全国联保与快速退换服务条。
- `ProductList-01` (`<productlist-01>`): 热门智能终端与数码配件陈列瀑布流。
- `Footer-01` (`<footer-01>`): 通讯数码官方服务矩阵与订阅中心页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
