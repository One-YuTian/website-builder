## Overview

Kitchen, bathroom, and home cleaning specialty store homepage assembled from utility navigation header, clean living hero carousel, kitchen essentials bestsellers grid, fast delivery service bar, and footer.

### Component Chain
`home-08: header-08 -> carousel-03 -> productlist-02 -> services-08 -> footer-02`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-08` | `<header-08>` | Kitchen and cleaning specialty navigation header with search and shortcuts |
| `Carousel-03` | `<carousel-03>` | Hero responsive full-width banner carousel for seasonal cleaning promotions |
| `ProductList-02` | `<productlist-02>` | High-frequency kitchen essentials bestseller products grid |
| `Services-08` | `<services-08>` | Fast shipping, eco-friendly guarantees, and customer return service badges |
| `Footer-02` | `<footer-02>` | Global site footer with customer support channels and secure payment badges |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
