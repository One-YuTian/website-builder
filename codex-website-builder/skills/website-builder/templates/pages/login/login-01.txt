## Overview

User account sign-in page, containing centered login card, brand badge skeleton, welcome headline, email field, password field (with visibility toggle), Remember Me checkbox, submit button, and link to registration.

### Layout & Regions
- `card-header`: Brand icon placeholder, main title, and subtitle text.
- `login-form`: Credentials form, password visibility toggle, and Remember Me option.
- `card-footer`: Divider and switch-to-register navigation link.

### Dimensions & Responsiveness
- Follows global design system, outer container uses `content-container` with PC max content width 1200px centered.
- Card max width 28rem (448px) centered, full width on mobile.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `is-submitting` | Form submission loading state | `boolean` | `false` |

### Events
- `auth-navigate`: Dispatched when clicking Sign Up or Forgot Password links.
- `auth-login`: Dispatched when submitting login credentials.

### JavaScript

```javascript
$(function() {
  const $form = $('#login-form');
  if (!$form.length) return;

  $form.on('submit', function(e) {
    e.preventDefault();
    $(this).trigger('login-submit');
  });

  $('[data-action="toggle-pwd"]').on('click', function(e) {
    e.preventDefault();
    const $input = $(this).siblings('input');
    const isPwd = $input.attr('type') === 'password';
    $input.attr('type', isPwd ? 'text' : 'password');
  });

  $('[data-action="goto-register"]').on('click', function(e) {
    e.preventDefault();
    $(this).trigger('auth-navigate', { target: 'register' });
  });

  $('[data-action="forgot-pwd"]').on('click', function(e) {
    e.preventDefault();
    $(this).trigger('auth-navigate', { target: 'forgot-password' });
  });
});
```
