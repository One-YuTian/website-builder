# Home-02

东南亚全品类综合电商首页，由促销导向吸顶导航、大幅活动轮播、热销主推网格、视觉营销横幅、个性化推荐瀑布流及页脚六大核心板块组合而成。

### 组合链路
`home-02：header-02->carousel-03->productlist-02->promotion-01->productlist-03->footer-02`

### 使用的组件 (Included Components)
- `Header-02` (`<header-02>`): 吸顶导航栏，含促销通告条、搜索框、分类快捷导航与用户/购物车操作区。
- `Carousel-03` (`<carousel-03>`): 首屏大幅活动轮播横幅，支持全宽响应式海报与自动轮播。
- `ProductList-02` (`<productlist-02>`): 热门主打爆款商品网格，内置响应式商品卡片与快速加购入口。
- `Promotion-01` (`<promotion-01>`): 沉浸式图文营销活动推广通栏，用于主推品类大促视觉传达。
- `ProductList-03` (`<productlist-03>`): 个性化猜你喜欢商品推荐瀑布流列表。
- `Footer-02` (`<footer-02>`): 全局站点页脚，包含服务保障徽章、多列分类导览与版权信息。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
