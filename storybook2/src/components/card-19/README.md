# Card-19

标准电商商品卡片组件，基于原生 Web Component 构建。支持 1:1 正方形主图骨架、折扣原价标签、2 行截断商品标题骨架、价格对比与加购/心愿单交互，具备网格（Grid）与列表（List）双展示模式。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 网格模式（grid）：正方形 1:1 图片比例，卡片由所在容器列等比分配撑满，单卡最大宽度 384px。
- 列表模式（list）：横向左右双栏排版，左侧固定 140px 缩略图，右侧信息自适应拉伸，单卡最大宽度 768px。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `product-id` | 商品唯一标识符 | `string` | `'product-01'` |
| `view-mode` | 排版模式（`'grid'` 网格或 `'list'` 列表） | `string` | `'grid'` |
| `discounted` | 是否展示划线原价对比与折扣浮标 | `boolean` | `false` |

### 事件机制
- `product-navigate`: 点击卡片主图或标题区域时冒泡派发商品详情跳转事件，携带商品唯一标识。
- `card-cart`: 点击快速加入购物车按钮时派发加购事件。
- `card-wishlist`: 点击心愿单爱心按钮时派发收藏状态切换事件。
