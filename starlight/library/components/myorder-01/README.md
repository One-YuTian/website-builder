# MyOrder-01

用户个人中心“我的订单”管理页面，包含面包屑导航、多笔历史订单卡片列表（订单号、状态徽章、商品缩略图列表、商品总数、支付方式、总计金额与查看详情/再次购买按键）以及无订单时的空状态占位。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。

### 尺寸与响应式
- 外层容器严格遵循 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），PC 最大内容宽度 1200px 居中对齐。
- 订单卡片列表自适应垂直堆叠排版，卡片圆角与间距保持响应式适配。
- 订单卡片底部汇总栏在桌面端双端对齐展示，在移动端自动堆叠自适应。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `limit` | 页面单次渲染最大订单数量 | `number` | `10` |

### 事件机制
- `order-navigate`: 点击查看详情、再次购买或继续购物时派发导航事件。
