# Shop-12

商城货架主列表页面，整合页面标题骨架、多维筛选侧边栏、排序工具栏、商品总数统计以及多列商品卡片自适应网格，支持价格升序/降序动态排序交互。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 `content-container`，PC 最大内容宽度 1200px 居中排版。
- 桌面端（1024px+）：4 列等宽商品卡片并排，左侧可配 260px 筛选栏。
- 移动端（小于 768px）：自适应为 2 列紧凑网格，顶部工具栏折行对齐。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `defaultSort` | 默认商品排序规则（`'default'`、`'asc'` 升序、`'desc'` 降序） | `string` | `'default'` |
| `itemCount` | 初始渲染商品数量 | `number` | `8` |

### 事件机制
- `product-navigate`: 点击商品卡片时派发商品跳转事件。
- `shop-sort`: 切换排序规则时触发列表重新渲染事件。
