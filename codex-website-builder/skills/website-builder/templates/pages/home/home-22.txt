## Overview

Collectible toys and building blocks homepage assembled from collectible toys navigation header, limited model hero carousel, IP series category tiles, mechanical brick kits grid, building contest promo banner, figures & blind boxes grid, and footer.

### Component Chain
`home-22: header-02 -> carousel-01 -> categories-06 -> productlist-02 -> promotion-01 -> productlist-01 -> footer-02`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-02` | `<header-02>` | Collectible toys navigation header with announcement bar and shortcuts |
| `Carousel-01` | `<carousel-01>` | Hero responsive banner carousel for limited-edition figures and bricks |
| `Categories-06` | `<categories-06>` | Collectible IP and theme series category tiles (mecha, architecture, supercar) |
| `ProductList-02` | `<productlist-02>` | Mechanical power and advanced building block kits grid |
| `Promotion-01` | `<promotion-01>` | Builders festival and speed-building contest promotional banner |
| `ProductList-01` | `<productlist-01>` | Figures, blind boxes, and collectible accessories showcase grid |
| `Footer-02` | `<footer-02>` | Toy collectors community and missing-part replacement warranty footer |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
