# Website Builder 0.7.1

## 生产目录

website_project现在返回directory和metadata_directory。directory是可发布的生产目录，只保存网站运行所需页面、脚本、样式、组件和正式素材；js/data.js是实际消费的唯一商品运行数据，可以保留。原始数据源、样本/seed、抓取响应、生成脚本、草稿、候选图、提示词、截图、测试文件和报告不进入生产目录。

项目控制状态、模板来源、设计、文案和图片记录保存到项目外.builder-state/projects/<project_id>/。website_write将根级website-builder.*.json记录自动分流到该目录；直接文件操作必须使用返回的metadata_directory绝对路径。常见临时目录、报告目录及tmp/bak/log/psd文件会被写入器拒绝。截图保存到metadata_directory/artifacts/screenshots，验收报告的技能约定也已同步修改。

旧项目仍可读取原有.website-builder.json及模板绑定，之后的管理写入使用新位置；不擅自删除或改写旧文件。内部原子替换使用的短生命周期临时文件在操作结束时清理，不作为交付产物。

## 图片和文案协作

图片技能明确先读取宿主imagegen技能，再调用其内置image_gen工具，按实际内容、槽位尺寸、比例、主体位置和文字留白生成。通常生成无字图，由HTML承载文案；Logo必要品牌字样或用户明确要求的图片文字除外。优先一张高质量主图自动裁切适配各端，无法保持主体与留白时才生成多端版本。ICON优先单色图形和透明背景，需要实底时采用统一纯色。

文案技能按场景决定长度：导航/按钮/提示短而清楚，Banner/页脚精炼，About Us和隐私政策可分节充分展开，避免重复空话；不编造业务事实、具体时效、安全保障或其他承诺。About Us有必要配图时可调用网站图片技能，政策页不强行加装饰图。实际已实现流程可客观描述，缺失业务资料明确列为待提供。

主技能对缺少的非商品文案、品牌/叙事图片和Mock商品数据主动调用对应技能；已有有效内容复用，不为了调用技能重建。图文不得遮挡主体、人物面部或关键物体，叠字只使用真实留白，优先选择相容的分栏/上下图文模板。逐端检查换行、裁切、清晰度与文字安全区。

## 必备导航

Header桌面导航及移动菜单都必须有Home、Shop、About Us、Contact Us四项的目标语言菜单，链接到真实存在的首页、商品列表、关于和联系页面。不能只放页脚、空链接或在某个断点隐藏且无替代入口。模板导航槽位不足时选择相容Header模板，用户明确要求优先于模板演示菜单数量。

## 验证与生效范围

已通过TypeScript、Vite/tsup构建、features、projects、templates及commerce回归。新增检查确认生产目录无控制清单/草稿/截图，管理记录正确分流，常见临时/报告写入被拒绝，旧项目读取兼容且旧文件不被改写。既有响应式Shop、登录与交易状态、截图就绪和5/7列画布检查继续通过。

技能frontmatter、管理JSON、agent YAML及内部链接已校验。这次修改的是插件源码与构建产物，没有生成新网站或图片，没有对历史网站执行自动清理或验收。新技能规则需重新安装/重载0.7.1后生效；技能定义不等同每个未来生成网站已经通过验收。
