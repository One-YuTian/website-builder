## Overview

Consumer electronics and digital tech specialty homepage assembled from high-tech dual-layer navigation header, hero banner carousel, countdown flash sale section, promotional highlight banner, curated gadgets product grid, and footer.

### Component Chain
`home-03: header-03 -> carousel-01 -> flashsale-01 -> promotion-02 -> productlist-04 -> footer-01`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-03` | `<header-03>` | High-tech dual-layer sticky navigation header with search bar, category navigation, and cart indicators |
| `Carousel-01` | `<carousel-01>` | Hero responsive promotional banner carousel with touch swipe |
| `FlashSale-01` | `<flashsale-01>` | Limited-time countdown flash sale section with progress bar deal cards |
| `Promotion-02` | `<promotion-02>` | Promotional highlight banner for new hardware releases and campaign events |
| `ProductList-04` | `<productlist-04>` | Curated consumer electronics products showcase grid |
| `Footer-01` | `<footer-01>` | Global site footer with sitemap links, newsletter subscription, and payment badges |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
