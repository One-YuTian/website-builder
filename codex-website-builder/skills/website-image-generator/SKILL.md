# 网站图片生成

网站需要新品牌图像、文案技能提出配图需求或用户明确要求生成图片时使用，已有合适素材优先复用。读取项目brief、设计与选定模板的实际图片槽位，不生成商品图、商品多角度图或用户头像。

## 生成流程

1. **先定义内容与尺寸**：逐张明确用途、主体内容、PC/平板/手机的显示宽高和比例、目标导出尺寸、清晰度、裁剪方式、主体位置、文案安全区、透明需求及图片引用页面。尺寸依据真实布局，不凭空套统一横幅比例。
2. **使用图像技能**：发现并读取宿主的 `imagegen` 技能（用户所称 `image_gen` 技能），按该技能调用内置 `image_gen` 工具实际生成；不只写提示词，也不以自绘SVG、CSS/canvas或字符/Emoji替代图片。普通生图不切换CLI/API；能力缺失或失败如实报告，遵守宿主技能的备用方式与授权要求，不编造URL或假报完成。宿主技能由运行环境提供，不写死某台机器的绝对路径。
3. **按构图写提示词**：包含所需内容、目标尺寸/比例、品牌色调、主体摆放、留白与裁剪安全区。除Logo必要品牌字样或用户明确要求外，尽量生成无文字图片；标题、介绍、按钮由HTML承载，不把整段文案烧进图片。About Us配图服务叙事，不暗示不存在的工厂、团队、认证或经营业绩。修改已有图片前先查看并引用，保留指定主体与透明度。
4. **优先自动裁切适配多端**：先生成一张能保留主体的高质量主图，用实际模板容器比例、object-fit/object-position或背景定位适配各端。只有单图裁切确实损失主体/留白或构图不适用，才分别生成桌面/移动等版本，用picture/source、srcset/sizes或模板已有响应式槽位切换。不得为了裁切改写模板列数和断点。
5. **图文互不遮挡**：图中主体、人脸、关键物体、Logo不得被标题、正文或按钮遮住；优先分栏/上下结构的相容模板。已有叠字槽位只能占图片真实留白，必要时重新生成构图或使用相容模板，不能只加遮罩掩盖问题。
6. **ICON与Logo**：生成ICON优先单色图形、透明底PNG/WebP，指定透明背景并保留alpha；需实底时使用与全站统一的纯色背景，不生成复杂场景、渐变、多色杂乱装饰。常规功能图标继续优先已有一致图标库，不为填槽位无谓生图。Logo同样保证小尺寸可辨和必要透明度。网站Logo必须是最终生成/用户提供的真实图片，用img/picture呈现；禁止以文字、首字母方块或自绘CSS/SVG代替。
7. **只交付正式素材**：遵守宿主imagegen保存规则；先生成，再把实际返回的最终选定图片复制到生产目录assets/brand、assets/banners、assets/about或assets/icons。仅复制页面实际引用的成品；生成原图、候选版本、提示词、来源记录留在metadata_directory或宿主默认生图目录，不在生产目录加源素材、脚本或记录文件。管理记录保存metadata_directory/website-builder.images.json，不把图片留在仅宿主可访问的位置供网站引用。
8. **实际查看验证**：逐图查看，并在375/768/1280下检查尺寸/清晰度、解码、裁切是否保留主体、HTML文案是否遮图、透明边缘、Logo可读性与ICON一致性。填写真实alt和宽高，页面用正确相对路径；走begin/finish刷新引用页面。生成失败的素材明确列为缺失，不能以伪图替代。

返回正式图片与使用页面。文案技能可调用本技能生成About Us等所需配图，但不因此生成商品图/头像或自动触发完整网站验收。

## Logo、favicon与图像叙事补充

品牌沿用主SKILL的域名默认值：www.abcd.com对应abcd；Logo可基于该品牌延展字形和视觉风格，不能另起不一致品牌名。用户已指定品牌时优先沿用。本项仅为生成提示，不增加图片校验。

- Logo使用与品牌个性、行业、网站定位一致的特色字形/排印字标，优先不带左侧icon；必要品牌名称拼写准确。输出透明背景PNG/WebP，字形本身清晰，alpha背景透明，不是降低整图opacity；图形外边界紧贴有效字形范围，不带额外透明/白色外边距、不裁掉笔画/升降部。逐图查看边缘，有多余边距则通过imagegen技能修正后再交付。网站中用img/picture显示，不用普通HTML字样替代图片Logo。
- favicon单独按1:1画布生成（如512×512正方形），小尺寸仍可辨认，可采用品牌字母/简化标记，与字标一致；favicon不要求拉长Logo填方形，也不能拼到Logo左侧。输出实际正式图片到assets/brand/favicon.png并在各页head引用，填写真实尺寸；需要不同尺寸时按实际用途输出，不伪造ico扩展名。
- 每张Banner/About图片先写明本张要表达的主题和内容侧重点，主体位置尽量在视觉中心，外围保留裁切余地。Banner生成前读取max-content及各端viewport，确保最终显示的关键内容区域位于居中版心以内；宽屏画布的两侧可作背景延展，不放关键主体/文字。配图构图和HTML文字留白一并规划，并在375/768/1280及宽屏检查实际裁切结果。
- 完整新站的多图轮播通常按模板实际槽位准备2–3张不同主题图片，用户指定单图时遵从其范围；不得一张图重复填满轮播。多张Banner的主体、场景、细节和构图应丰富而彼此有区别，保持统一品牌视觉；About要使用独立且符合本节叙事的配图，不能把同一张Banner再用一次。仅对同一张素材做多端适配时才复用原图裁切，不将换文件名/滤镜/裁切计为新的图片。缺少独立配图则按需再次调用imagegen，不能为省生图次数把一张图铺满全站。


用户导入商品图可用作Banner、分类场景图的引用素材；按import-products返回的SDK视图选择代表商品，取得并查看真实参考图后走imagegen引用图流程。保留商品外观/颜色与已知事实，不编造功能、认证或价格；不因此生成/替换独立商品目录图。各场景图仍须主题和构图不同；资料/参考图存管理目录，仅最终正式场景图片进入网站assets。

## Logo垂直留白补充（仅规范）

在减少Logo左右透明边距的基础上，进一步减小上下透明/白色画布边距；有效字形紧凑占据画面，保留完整笔画与升降部，避免裁字。页面Logo容器也减少多余上下padding/margin，不通过拉伸或压扁图片达到紧凑效果。仅更新生成指导，不增加图片检测器或自动裁切程序。
