# Promotion-02

商业促销横幅与活动展示板块，支持多栏等宽并排或不对称拼贴排版，内嵌大幅营销背景图、高饱和度折扣标签与快速行动 CTA 按钮。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 遵循全局设计规范，外层容器使用 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），最大宽度 1200px 居中排版。
- 桌面端（1024px+）：2~3 栏拼贴布局，卡片高度 240px~360px。
- 移动端（小于 768px）：单栏垂直层叠流动排布。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `columns` | 并排促销展板列数 | `number` | `2` |

### 事件机制
- `promo-navigate`: 点击单张促销横幅或行动按钮时派发跳转事件。
