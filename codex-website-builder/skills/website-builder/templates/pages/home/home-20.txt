## Overview

Premium menswear and business-casual apparel homepage assembled from menswear navigation header, gentlemen lookbook hero carousel, business attire bestsellers grid, VIP tailoring promotional banner, casual wear collection, and footer.

### Component Chain
`home-20: header-02 -> carousel-03 -> productlist-02 -> promotion-07 -> productlist-03 -> footer-02`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-02` | `<header-02>` | Menswear sticky navigation header with seasonal announcement bar and shortcuts |
| `Carousel-03` | `<carousel-03>` | Gentlemen lookbook hero responsive full-width banner carousel |
| `ProductList-02` | `<productlist-02>` | Business suits, outerwear, and blazers bestseller products grid |
| `Promotion-07` | `<promotion-07>` | Bespoke tailoring and VIP membership rewards promotional banner |
| `ProductList-03` | `<productlist-03>` | Weekend casual wear and leather accessories showcase grid |
| `Footer-02` | `<footer-02>` | Premium menswear boutique customer care and warranty footer |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
