# Home-04

强调促销氛围与转化效率的综合电商首页，由大促吸顶导航、首屏活动轮播、热销爆款网格、折扣营销通栏、综合好物瀑布流及页脚组合而成。

### 组合链路
`home-04：header-04->carousel-03->productlist-02->promotion-02->productlist-01->footer-02`

### 使用的组件 (Included Components)
- `Header-04` (`<header-04>`): 促销导向吸顶导航栏，顶部含营销倒计时/折扣通告栏与核心操作入口。
- `Carousel-03` (`<carousel-03>`): 首屏全宽营销活动轮播，提供大幅促销视觉传达。
- `ProductList-02` (`<productlist-02>`): 热销主推商品网格，聚焦高转化率主打产品。
- `Promotion-02` (`<promotion-02>`): 主推折扣营销横幅，强化限时优惠心智。
- `ProductList-01` (`<productlist-01>`): 多品类好物瀑布流陈列，满足深度选购与浏览需求。
- `Footer-02` (`<footer-02>`): 全局服务保障页脚，包含客户信赖标识与分类链接。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
