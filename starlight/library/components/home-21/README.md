# Home-21

母婴生活与儿童益智玩具乐园首页，由童趣现代导航、益智首屏轮播、安全环保承诺条、年龄段导购入口、益智积木网格、亲子生活精选及安心页脚组合而成。

### 组合链路
`home-21：header-05->carousel-01->services-04->categories-05->productlist-02->productlist-03->footer-01`

### 使用的组件 (Included Components)
- `Header-05` (`<header-05>`): 趣味母婴商城吸顶导航，方便快速检索儿童年龄段用品。
- `Carousel-01` (`<carousel-01>`): 欢乐益智玩具首屏轮播大图，充满童趣与活力。
- `Services-04` (`<services-04>`): 母婴环保无毒材质、安全检测认证与安心退换服务条。
- `Categories-05` (`<categories-05>`): 年龄段与发展阶段玩具分类导购入口。
- `ProductList-02` (`<productlist-02>`): 热门益智拼插积木与早教教具网格。
- `ProductList-03` (`<productlist-03>`): 亲子互动玩乐与母婴日常护理好物列表。
- `Footer-01` (`<footer-01>`): 母婴乐园安心保障与正品溯源页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
