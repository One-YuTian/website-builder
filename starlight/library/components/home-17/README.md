# Home-17

手机与移动通讯数码垂直首页，由经典吸顶导航、旗舰手机发布轮播、手机配件秒杀专区、热销智能终端网格及官方服务页脚组合而成。

### 组合链路
`home-17：header-01->carousel-20->flashsale-01->productlist-01->footer-01`

### 使用的组件 (Included Components)
- `Header-01` (`<header-01>`): 经典吸顶导航栏，方便快速查找手机型号与配件品类。
- `Carousel-20` (`<carousel-20>`): 旗舰新品手机首屏活动轮播，主打核心参数与质感大图。
- `FlashSale-01` (`<flashsale-01>`): 充电宝、手机壳与保护膜限时秒杀板块。
- `ProductList-01` (`<productlist-01>`): 热销智能手机与移动终端商品展示瀑布流。
- `Footer-01` (`<footer-01>`): 官方验机正品认证与售后服务页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
