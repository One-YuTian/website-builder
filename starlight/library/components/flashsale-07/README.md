# FlashSale-07

限时秒杀双栏营销板块，左侧 1/3 为大促倒计时海报卡片，右侧 2/3 为 Swiper 轮播轨道及多列自适应秒杀商品卡片。

### 强制规范要求
1. **左侧倒计时海报底图**：左侧必须采用主题背景色（`bg-primary`）配合背景图片/纹理垫底（`bg-cover bg-center`）作为视觉基础，形成强烈的限时大促视觉吸引力。
2. **右侧必须使用 Swiper 轮播**：右侧商品展示区域必须使用 Swiper 轮播轨道（`.flash-sale-swiper-07`），配置左右切换导航箭头。
3. **商品卡片组件必须使用 `FlashCard` (`<flashcard-01>`)**：轮播内的所有卡片项必须使用专属秒杀卡片组件 `flashcard-01`，内置秒杀价格、折扣角标及库存售罄进度条，严禁使用普通通用 Card 替换。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 外层容器严格遵循 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），PC 最大内容宽度 1200px 居中对齐。
- 桌面端（1024px+）：展示 3~4 列秒杀商品卡片。
- 移动端（小于 768px）：单行双列展示，超出视口宽度通过横向滑动手势无缝浏览。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `limit` | 秒杀商品展示数量上限 | `number` | `4` |
| `endTime` | 倒计时截止时间戳 | `string` | `'2026-12-31'` |

### 事件机制
- `flashsale-navigate`: 点击查看更多秒杀商品时派发导航事件。
- `product-navigate`: 点击秒杀卡片时派发单品跳转事件，携带商品标识。
