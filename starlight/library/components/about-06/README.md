# About-06

关于我们企业品牌形象页面，整合全宽主视觉横幅、品牌创立图文故事、核心数据指标看板、企业里程碑时间轴以及核心团队成员风采。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），PC 最大内容宽度 1200px 居中排版。
- 桌面端（1024px+）：多栏画册排版，主视觉图文对齐留白宽裕。
- 移动端（小于 1024px）：图文双栏转为单列垂直排布，数据看板转为 2 列紧凑网格。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `theme` | 主题配色模式 | `'light' \| 'dark'` | `'light'` |

### 事件机制
- `about-navigate`: 点击团队成员社交链接或企业行动按钮时派发事件。
