## Overview

Outdoor adventure gear and camping equipment homepage assembled from tech navigation header, rugged outdoor hero banner carousel, outdoor warranty service bar, limited-time gear flash sale, core expedition equipment grid, and footer.

### Component Chain
`home-12: header-03 -> carousel-14 -> services-02 -> flashsale-01 -> productlist-04 -> footer-01`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-03` | `<header-03>` | Dual-layer navigation header for rapid category exploration (hiking, camping, climbing) |
| `Carousel-14` | `<carousel-14>` | Rugged outdoor hero banner carousel emphasizing wilderness and technical gear |
| `Services-02` | `<services-02>` | Outdoor gear professional warranty, gear safety testing, and support bar |
| `FlashSale-01` | `<flashsale-01>` | Limited-time outdoor gear countdown flash sale section |
| `ProductList-04` | `<productlist-04>` | Core expedition and technical equipment showcase grid |
| `Footer-01` | `<footer-01>` | Global outdoor adventure site footer with community links and newsletter signup |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
