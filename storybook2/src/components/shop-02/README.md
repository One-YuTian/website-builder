# Shop-02

带左侧固定筛选侧边栏的商城商品列表页面组件，支持类目选择、价格范围输入过滤与价格升降序排序。

## 区域划分
- `sidebar`: 桌面端左侧固定侧边栏区域，包含分类下拉与价格区间输入控制。
- `toolbar`: 右侧主内容顶部工具栏，包含价格排序下拉框与商品统计数量。
- `products-grid`: 2 列至 3 列响应式商品卡片网格容器区域。

## 尺寸与响应式
- 页面容器：由全局 `content-container` 控制内容最大宽度。
- 侧边栏：桌面端固定宽度 256px 并吸顶停靠（`sticky top-24`），移动与平板端支持下拉手风琴折叠展开。
- 商品网格：移动端 2 列，平板及桌面端扩展为 3 列，间隙自适应 16px 至 24px。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `sortOrder` | 价格排序规则（`default` / `asc` / `desc`） | `string` | `'default'` |

## 事件机制
- `product-navigate`: 子级商品卡片点击时冒泡派发的商品交互事件。

## 独立使用说明
作为独立页面级模板使用，直接渲染基础 HTML 结构并通过内置脚本驱动卡片与排序交互。
