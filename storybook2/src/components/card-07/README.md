# Card-07

轻量卡片组件，具有 5:4 比例主图、浮动心形收藏夹按钮、品牌标签与底部全宽加购操作按钮。

## 区域划分
- `image-area`: 顶部或左侧 5:4 比例商品主图、左上角折扣标与右上角浮动收藏夹按钮区域。
- `content-area`: 品牌标签、双行商品标题、当前价格与加购操作按钮区域。

## 尺寸与响应式
- 网格视图：纵向流式自适应父级网格，主图比例为 5:4。
- 列表视图：横向图文排版，主图区域宽度为 112px（小屏）或 192px（大屏）。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `product-id` | 商品唯一标识 | `string` | `'product-01'` |
| `view-mode` | 排版布局模式（`grid` 或 `list`） | `string` | `'grid'` |
| `discounted` | 折扣状态与原价显示标记 | `boolean` | `false` |

## 事件机制
- `product-navigate`: 点击卡片、加购按钮或收藏夹时派发商品交互事件。

## 独立使用说明
组件作为独立 WebComponent 引入，可直接嵌入网格列表或轮播板块容器中使用。
