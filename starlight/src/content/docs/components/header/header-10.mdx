## Overview

Global sticky top navigation bar component, integrating brand LOGO skeleton, site-wide predictive search bar, user authentication & account portal, wishlist & cart counter badges, and horizontal category navigation menu. Features sticky positioning upon scroll and lightweight slide-out mobile drawer navigation.

### Layout & Detailed Region Breakdown
- `logo-area`: **Brand identity region**, fixed height 40px embedding neutral `LOGO` rounded rectangle skeleton on the left; dispatches `header-navigate` to return to home page upon click.
- `search`: **Site-wide predictive search region**, high-radius pill container containing search placeholder text skeleton, clear icon, and search submit button; dispatches `header-search-input` on typing and displays up to 6 suggestion items with thumbnails in absolute dropdown panel (`search-suggestions`).
- `navigation`: **Desktop primary navigation menu region**, horizontally aligned on viewports 1024px+, featuring 4~6 top category nav link skeletons (Home, Shop, Categories, About, Contact); triggers route events on click.
- `account-panel`: **User auth and account portal region**, triggered by circular user avatar icon; navigates to login when unauthenticated, and opens dropdown menu with user profile skeleton, orders entry, and logout button when logged in.
- `action-icons`: **Quick action icon group**, located at top-right corner, containing wishlist heart icon with badge, shopping cart drawer trigger with primary colored counter badge, and mobile hamburger button visible under 1024px.
- `mobile-drawer`: **Mobile slide-out drawer region**, smoothly slides out from left on mobile viewports (max width 320px), containing brand LOGO skeleton, close cross icon, vertical nav list, and bottom login/register action buttons.

### Dimensions & Responsiveness
- Desktop (1024px+): Fixed height 68px~76px, follows global `content-container` with max content width 1200px centered, supports sticky positioning during page scrolling.
- Tablet & Mobile (under 1024px): Horizontal category list collapses, main bar retains Logo, search, and action icons; hamburger button triggers 320px smooth slide-out drawer.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `theme` | Color theme mode, supports dark and light inversion | `'dark' \| 'light'` | `'dark'` |
| `is-logged-in` | User authentication state, toggles account portal display | `boolean` | `false` |
| `cart-count` | Badge counter number on shopping cart icon | `number` | `0` |
| `wishlist-count` | Badge counter number on wishlist icon | `number` | `0` |

### Events
- `header-navigate`: Dispatched when clicking brand logo, nav links, or account menu items.
- `header-search`: Dispatched when submitting search form or pressing enter.
- `header-search-input`: Dispatched in real time as search input content changes for predictive suggestions.
- `header-cart`: Dispatched when clicking the cart icon to open drawer.
