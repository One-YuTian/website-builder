# Home-10

时尚女装与潮流服饰穿搭首页，由优雅女装导航、当季新品穿搭首屏轮播、热卖爆款网格、换季大促营销通栏、配饰单品瀑布流及页脚组合而成。

### 组合链路
`home-10：header-10->carousel-01->productlist-02->promotion-01->productlist-03->footer-02`

### 使用的组件 (Included Components)
- `Header-10` (`<header-10>`): 优雅精品女装风格吸顶导航，含换季主题导航与快捷入口。
- `Carousel-01` (`<carousel-01>`): 当季新款穿搭首屏响应式轮播海报。
- `ProductList-02` (`<productlist-02>`): 新品首发与当红热卖服饰四列网格。
- `Promotion-01` (`<promotion-01>`): 换季大促与限时折扣沉浸式图文通栏。
- `ProductList-03` (`<productlist-03>`): 百搭单品与潮流配饰个性化展示列表。
- `Footer-02` (`<footer-02>`): 时尚商城服务保障页脚，包含尺码指南与退换保障。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
