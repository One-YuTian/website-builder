## Overview

Shop catalog page, integrating page title, multi-dimensional filter sidebar, sorting toolbar, item counter, and responsive multi-column product card grid.

### Layout & Detailed Region Breakdown
- `page-header`: **Page lead-in region**, containing full-width page headline skeleton, breadcrumb navigation (Home > Shop), and category intro copy.
- `filter-sidebar`: **Filter sidebar on the left** (side-by-side on desktop, sliding drawer on mobile), containing price range slider, brand checkboxes, color swatches, and size blocks.
- `toolbar`: **Product list control toolbar**, containing matching product count text (e.g. Showing 1-12 of 48 products), grid/list layout switch, and sort dropdown selector.
- `products-grid`: **Main product showcase grid**, responsive multi-column card matrix mounting Card components.
- `pagination-bar`: **Pagination bottom bar**, containing previous, numeric page buttons (1, 2, 3...), and next button.

### Dimensions & Responsiveness
- Follows `content-container` with PC max content width 1200px centered.
- Desktop (1024px+): 4 equal columns with optional 260px filter sidebar on left.
- Mobile (under 768px): 2 compact columns with wrapped toolbar.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `defaultSort` | Default sorting rule | `string` | `'default'` |
| `itemCount` | Initial product count | `number` | `8` |

### Events
- `product-navigate`: Dispatched when clicking product card.
- `shop-sort`: Dispatched when changing sorting order.
