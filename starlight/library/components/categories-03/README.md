# Categories-03

品类导航与分类展示板块，包含板块大标题、圆形或圆角方形品类卡片网格以及商品数量统计徽章，支持鼠标悬浮微动交互与分类快速路由。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 外层容器使用 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），最大宽度 1200px 居中对齐。
- 桌面端（1024px+）：4~6 列圆形/方形品类卡片均匀平铺。
- 移动端（小于 768px）：自适应为 3 列紧凑网格或横向触摸滑块流。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `limit` | 最大展示分类数量 | `number` | `6` |

### 事件机制
- `category-navigate`: 点击单张品类卡片时派发跳转事件，携带分类 ID。
