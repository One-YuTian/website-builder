# ProductList-02

电商货架核心商品网格板块，集成板块大标题、快速类目筛选标签、4~5 列响应式商品卡片矩阵以及底部查看全部入口。

### 区域划分与内容说明
- `section-header`: **板块顶部标题栏**，包含左侧加粗板块主标题骨架（如“Featured Products / 热门精选”）、副标题品类描述，以及右侧带有箭头指示的“查看更多 / View All”超链接入口。
- `filter-tabs`: **快捷分类筛选标签栏**，横向排列药丸状分类标签组（All、New Arrivals、Best Sellers、On Sale 等），点击切换展示不同分类商品。
- `product-grid`: **响应式商品卡片陈列网格**，桌面端（1024px+）展示为 4~5 列等宽网格，平板端展示为 3 列，移动端自适应为 2 列紧凑网格；内部挂载多张完整商品卡片。
- `load-more`: **底部行动区**，居中展示带有边框的“加载更多 / Load More”按钮骨架，支持动态加载后续批次商品。

### 尺寸与响应式
- 外层容器严格遵循 `content-container`，PC 最大内容宽度 1200px 居中对齐。
- 桌面端（1024px+）：4~5 列网格排布，间隙 16px~24px。
- 平板端（768px~1023px）：自适应重排为 3 列网格。
- 移动端（小于 768px）：自适应为 2 列紧凑网格，间距 12px，卡片高度自适应拉平。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `containerId` | 商品挂载容器选择器 ID | `string` | `'productlist-01-grid'` |
| `limit` | 单页渲染最大商品数量 | `number` | `8` |

### 事件机制
- `product-navigate`: 点击单张商品卡片时冒泡派发商品跳转事件。
- `filter-change`: 切换筛选标签时派发分类更新事件。
