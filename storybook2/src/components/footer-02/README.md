# Footer-02

电商全站标准页脚组件，整合品牌 LOGO 骨架、企业使命介绍、多列分类导航矩阵、社交媒体图标占位、安全信任背书与底部版权备案声明栏，具备自适应响应式栅格布局。

### 区域划分与内容说明
- `brand-section`: **品牌形象与企业愿景区**，位于页脚左侧首列，上方包含 `LOGO` 品牌标识骨架，下方包含 2~3 行企业简介与愿景介绍文本骨架，底部并排展示 4 个圆形社交媒体图标骨架（Facebook、Instagram、Twitter、YouTube 等）。
- `nav-columns`: **多列结构化导航链接矩阵区**，由 3~4 列等宽垂直列表组成（分别对应购物指南、客户服务、关于我们、合规条款），每列包含 1 行加粗大标题骨架及 4~5 行子页面超链接文本骨架。
- `newsletter-box`: **邮件订阅与优惠券领取区**，包含单行邮箱输入框骨架与“订阅/Subscribe”按钮，用于收集用户邮件线索。
- `bottom-bar`: **全站底部版权与信任背书栏**，采用顶部分割线隔开，包含左侧全站版权年份/备案编号文本骨架，以及右侧多种主流支付渠道信任徽标（Visa、Mastercard、PayPal 等支付卡片骨架）。

### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 `content-container`，PC 最大内容宽度 1200px 居中排版。
- 桌面端（1024px+）：3 列或 4 列网格并排平铺，各列间距 32px~48px。
- 移动端（小于 1024px）：自适应转为单列纵向流式排布，各列之间自然留白分隔，保证触控区域高度不低于 44px。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `columns` | 页脚主内容列数配置 | `number` | `3` |

### 事件机制
- `footer-navigate`: 点击页脚任一链接或社交媒体图标时派发导航跳转事件，携带链接目标参数。
