# Shop-04

具有单选类目列表与浅色圆角控制条的商城页面组件，支持类目单选、区间价格过滤与响应式四列商品网格。

## 区域划分
- `sidebar`: 桌面端左侧单选分类树与价格输入区间侧边栏区域。
- `toolbar`: 右侧主内容区浅色背景工具条，包含价格排序下拉框与商品统计总数。
- `products-grid`: 2 列至 4 列响应式商品卡片网格容器区域。

## 尺寸与响应式
- 页面容器：由全局 `content-container` 控制内容最大宽度。
- 侧边栏：桌面端固定宽度 256px 并吸顶停靠（`sticky top-24`），移动与平板端提供筛选侧边抽屉。
- 商品网格：移动端 2 列，平板扩展为 3 列，桌面端 `lg` 视口为 4 列，间隙自适应 16px 至 24px。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `sortOrder` | 价格排序规则（`default` / `asc` / `desc`） | `string` | `'default'` |

## 事件机制
- `product-navigate`: 子级商品卡片点击时冒泡派发的商品交互事件。

## 独立使用说明
作为独立页面级模板使用，直接渲染基础 HTML 结构并通过内置脚本驱动卡片与排序交互。
