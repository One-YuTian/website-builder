# Wishlist-01

用户心愿单与商品收藏清单页面，包含页面大标题、收藏商品总数提示、收藏商品卡片矩阵，支持单项一键转移至购物车或移除操作。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），PC 最大内容宽度 1200px 居中排版。
- 桌面端（1024px+）：4 列等宽商品卡片并排。
- 移动端（小于 768px）：自适应为 2 列紧凑网格。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `itemCount` | 收藏商品总件数 | `number` | `4` |

### 事件机制
- `wishlist-remove`: 移除收藏商品时派发事件。
- `wishlist-move-to-cart`: 将商品移至购物车时派发事件。
