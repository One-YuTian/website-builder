# Home-20

品质男装与商务休闲穿搭首页，由商务男装吸顶导航、绅士型格首屏轮播、正装热卖网格、定制会员通栏、休闲服饰列表及品质页脚组合而成。

### 组合链路
`home-20：header-02->carousel-03->productlist-02->promotion-07->productlist-03->footer-02`

### 使用的组件 (Included Components)
- `Header-02` (`<header-02>`): 商务男装吸顶导航栏，含季节通报条与品类入口。
- `Carousel-03` (`<carousel-03>`): 绅士型格首屏大幅质感轮播海报。
- `ProductList-02` (`<productlist-02>`): 商务正装、西服与夹克大衣热销网格。
- `Promotion-07` (`<promotion-07>`): 私享定制服务与VIP会员礼遇通栏。
- `ProductList-03` (`<productlist-03>`): 周末休闲服饰与皮具配饰精选瀑布流。
- `Footer-02` (`<footer-02>`): 品质男装店服务保障与售后说明页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
