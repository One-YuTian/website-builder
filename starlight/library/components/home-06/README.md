# Home-06

高端腕表与精品配饰轻奢首页，由极简典雅导航、大幅质感轮播、双格甄选推广位、品牌视觉故事通栏、腕表配饰陈列列表及品质保障页脚组合而成。

### 组合链路
`home-06：header-06->carousel-03->promotion-03->promotion-10->productlist-03->footer-02`

### 使用的组件 (Included Components)
- `Header-06` (`<header-06>`): 极简典雅轻奢风格吸顶导航，强化品牌高端调性。
- `Carousel-03` (`<carousel-03>`): 首屏全宽大幅质感海报轮播，呈现高级视觉陈列。
- `Promotion-03` (`<promotion-03>`): 甄选双格特色推广位，用于主推男女表款或当季新品。
- `Promotion-10` (`<promotion-10>`): 品牌视觉故事通栏，展示精湛制表工艺与品牌理念。
- `ProductList-03` (`<productlist-03>`): 经典腕表与配饰产品网格，精致呈现单品细节。
- `Footer-02` (`<footer-02>`): 品质保障页脚，包含官方保修、原厂认证及服务导航。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
