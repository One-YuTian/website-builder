## Overview

Artisan cashmere and handmade craft workshop homepage assembled from cultural craft navigation header, workshop hero carousel, illustrated craft category navigation tiles, handcrafted products grid, and footer.

### Component Chain
`home-09: header-09 -> carousel-12 -> categories-02 -> productlist-01 -> footer-01`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-09` | `<header-09>` | Artisan craft specialty navigation header conveying authentic workshop identity |
| `Carousel-12` | `<carousel-12>` | Handmade crafts artisanal hero carousel showcasing weaving and carving processes |
| `Categories-02` | `<categories-02>` | Illustrated craft category navigation tiles for artisan specialties |
| `ProductList-01` | `<productlist-01>` | Handcrafted artisan products grid showcase with detailed cards |
| `Footer-01` | `<footer-01>` | Global artisan workshop footer with worldwide shipping and origin guarantee |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
