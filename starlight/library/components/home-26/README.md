# Home-26

现代空间美学与家居整装首页，由促销导向吸顶导航、全宽质感家居轮播、现代简约家具专区、全屋软装焕新通栏、室内装饰摆件列表及品质页脚组合而成。

### 组合链路
`home-26：header-04->carousel-03->productlist-02->promotion-09->productlist-03->footer-02`

### 使用的组件 (Included Components)
- `Header-04` (`<header-04>`): 促销吸顶导航栏，含家居节倒计时通报条与快捷操作。
- `Carousel-03` (`<carousel-03>`): 首屏大幅舒适质感家居轮播海报。
- `ProductList-02` (`<productlist-02>`): 现代简约家具热销主推四列网格。
- `Promotion-09` (`<promotion-09>`): 全屋定制与软装焕新大促视觉营销通栏。
- `ProductList-03` (`<productlist-03>`): 室内装饰摆件、灯具与软装配件精选列表。
- `Footer-02` (`<footer-02>`): 现代家居服务保障与无忧售后页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
