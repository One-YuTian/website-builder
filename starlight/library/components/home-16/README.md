# Home-16

家具软装与全屋空间整装首页，由经典吸顶导航、空间分类多格导览、客厅卧室大件家具网格、软装配饰精选列表、大件送装服务条及页脚组合而成。

### 组合链路
`home-16：header-01->categories-04->productlist-02->productlist-01->services-03->footer-01`

### 使用的组件 (Included Components)
- `Header-01` (`<header-01>`): 全站经典吸顶导航栏，含搜索框、分类快捷导航与购物车。
- `Categories-04` (`<categories-04>`): 家具空间分类多格导览（客厅、卧室、餐厅、书房）。
- `ProductList-02` (`<productlist-02>`): 客厅与卧室主推大件家具四列网格。
- `ProductList-01` (`<productlist-01>`): 软装生活用品与家居配饰精选陈列。
- `Services-03` (`<services-03>`): 大件家具免费送装上门与质保承诺条。
- `Footer-01` (`<footer-01>`): 全屋家具商城全局底部矩阵与咨询入口。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
