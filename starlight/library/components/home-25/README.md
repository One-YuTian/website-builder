# Home-25

现代多元潮流百货集市首页，由轻奢现代导航、先锋美学活动轮播、当红单品精选网格、灵感集市大促通栏、多元生活好物瀑布流及页脚组合而成。

### 组合链路
`home-25：header-06->carousel-30->productlist-02->promotion-11->productlist-01->footer-02`

### 使用的组件 (Included Components)
- `Header-06` (`<header-06>`): 现代多元潮流吸顶导航栏，兼顾高颜值与实用性。
- `Carousel-30` (`<carousel-30>`): 潮流先锋美学活动轮播大图，呈现高饱和度视觉冲击。
- `ProductList-02` (`<productlist-02>`): 当红热门单品精选四列陈列网格。
- `Promotion-11` (`<promotion-11>`): 灵感集市狂欢大促视觉营销通栏。
- `ProductList-01` (`<productlist-01>`): 多元生活潮流好物瀑布流列表。
- `Footer-02` (`<footer-02>`): 潮流集市服务承诺与全方位售后保障页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
