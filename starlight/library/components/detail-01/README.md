# Detail-01

商品详情页面（PDP），包含多视角画廊预览、购买决策核心区（标题、原价现价、SKU 规格选择器、步进器、加购/购买按键）及超长内容智能折叠展示更多面板。

### 折叠显示更多（Expand / Collapse）交互方案与规范
1. **动态高度溢出检测（Dynamic Overflow Detection）**：
   - 折叠区域（商品描述 `max-h-24`、规格参数表 `max-h-56`、用户评价列表 `max-h-72`）设置最大高度约束。
   - 页面初始化时自动检测内容实际高度与容器约束高度：若文案或内容过短未超出限定高度，底部渐变遮罩（`.collapsible-fade`）和“展开/折叠”按键（`.collapsible-toggle`）**必须保持隐藏**（`hidden`），严禁无内容溢出时盲目展示折叠按键。
   - 仅在内容实际高度超出限定高度时，才自动激活显示渐变遮罩与切换按钮。
2. **双向展开与折叠支持（Bidirectional Expand / Collapse）**：
   - 点击展开按键时移除高度限制（添加 `max-h-none`），隐藏渐变遮罩，指示箭头顺时针旋转 180°。
   - 再次点击时重新收起折叠恢复限高，显示底部渐变遮罩，箭头复位，支持无缝双向循环交互。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），PC 最大内容宽度 1200px 居中排版。
- 桌面端（1024px+）：采用 1:1 双栏并排（左侧画廊 550px，右侧购买信息 550px）。
- 移动端（小于 1024px）：双栏自动转为单列垂直排布，画廊支持手势横向滑动，购买按钮贴底对齐。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `productId` | 当前详情展示的商品唯一标识符 | `string` | `'product-01'` |

### 事件机制
- `product-navigate`: 点击关联推荐商品时派发页面跳转事件。
- `gallery-change`: 切换缩略图视点时派发画廊更新事件。
