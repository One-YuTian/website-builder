# 模板使用与文案边界

所有模板库提供的组件、板块与页面均可直接选用，包括限时抢购、倒计时、促销、服务权益、退换货及货到付款相关模块，不需要逐项征求确认。模板选择由页面设计与内容需要决定，不以“未经确认的促销承诺”为由删除或回避Home-03等模板中的模块。Home仍按主技能的有限组合规则执行，其伪代码不作为生产实现；模板均可使用，不等于首页可无限增删板块。

结构使用与具体文案分别处理：保留合适模块，谨慎填充文字和数据。没有完整促销资料时可使用“精选好物”“本期推荐”等中性内容承接原模块，而不是直接不采用。折扣、原价、价格、评分、销量等商品数值从数据技能/SDK取得，不为填模板编造数值；有倒计时时读取或明确设置本项目活动结束时间，不冒充外部已存在的活动或反复重置制造紧迫感。
