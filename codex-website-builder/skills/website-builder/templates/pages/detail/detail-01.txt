## Overview

Product Detail Page (PDP), featuring multi-view product gallery skeleton, right-hand purchase action zone (product title, price comparison, color/size variant selectors, quantity stepper, Add to Cart & Buy Now buttons), and specifications accordion.

### Layout & Regions
- `gallery`: Product image gallery skeleton with main view and thumbnail carousel.
- `purchase-box`: Right-hand buy box with title, pricing, variant pickers, stepper, and CTA buttons.
- `specifications`: Product details and specifications accordion panel.

### Dimensions & Responsiveness
- Follows global design system, outer container uses `content-container` with PC max content width 1200px centered.
- Desktop (1024px+): 5:4 or 1:1 two-column split layout.
- Mobile (under 1024px): Single-column vertical stack with horizontal swipe gallery.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `product-id` | Product identifier | `string` | `'detail-product-1'` |

### Events
- `detail-add-cart`: Dispatched when clicking Add to Cart.
- `detail-buy-now`: Dispatched when clicking Buy Now.

### JavaScript

```javascript
$(function() {
  const $qtyInput = $('#qty-input');
  if (!$qtyInput.length) return;

  $('#qty-minus').on('click', function() {
    let val = parseInt($qtyInput.val(), 10) || 1;
    if (val > 1) $qtyInput.val(val - 1);
  });

  $('#qty-plus').on('click', function() {
    let val = parseInt($qtyInput.val(), 10) || 1;
    if (val < 99) $qtyInput.val(val + 1);
  });

  let thumbnailsSwiper = null;
  if (typeof Swiper !== 'undefined' && $('.thumbnails-swiper').length) {
    thumbnailsSwiper = new Swiper('.thumbnails-swiper', {
      slidesPerView: 'auto',
      spaceBetween: 8,
      freeMode: true,
      watchSlidesProgress: true
    });
  }

  $('#thumb-prev').on('click', function() {
    thumbnailsSwiper?.slidePrev();
  });

  $('#thumb-next').on('click', function() {
    thumbnailsSwiper?.slideNext();
  });

  $('[data-region="gallery"] [role="button"]').on('click', function() {
    $('[data-region="gallery"] [role="button"]').removeClass('border-2 border-primary').addClass('border border-outline/50');
    $(this).removeClass('border border-outline/50').addClass('border-2 border-primary');
  });

  $('#add-to-cart-btn, #buy-now-btn').on('click', function() {
    const event = new CustomEvent('product-navigate', {
      bubbles: true,
      composed: true,
      detail: { action: $(this).attr('id'), quantity: parseInt($qtyInput.val(), 10) || 1 }
    });
    this.dispatchEvent(event);
  });

  $('#product-tabs-nav .tab-btn').on('click', function() {
    const tab = $(this).data('tab');
    $('#product-tabs-nav .tab-btn').removeClass('border-primary text-primary').addClass('border-transparent text-muted');
    $(this).addClass('border-primary text-primary').removeClass('border-transparent text-muted');

    $('.tab-panel').addClass('hidden');
    $('#' + tab + '-panel').removeClass('hidden');
  });
});
```
