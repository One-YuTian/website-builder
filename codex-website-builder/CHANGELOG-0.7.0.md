# Website Builder 0.7.0

本次修改插件源码、技能与运行时；没有重生成已有用户网站，也没有修改 storybook、storybook2、template、website 或 Starlight 的来源文件。

## Shop 差异原因与修复

四个 Shop 过去共用同一份 Overview：都声称可带约260px侧栏、桌面四列。但实际 shop-01 没有侧栏，shop-02/12 桌面只有三列；shop-04 没有页面标题区。根据概述重新设计会直接引入错误区域与列数。

此外，模板脚本是演示商品、price 字段与旧 card-01 标签；直接接入实际 SDK 而未同步替换数据、final_price、组件标签/选择器会造成商品或交互错误。主技能中的统一圆角、边距建议又与严格保留模板的要求相互冲突。

修复为逐模板布局契约，供候选摘要、doc/code、CLI 读取器共同使用；保留原模板镜像字节。Shop 接入必须读取配套 Card 的完整代码，明确替换数据/标签，并保持筛选、抽屉与视图切换。所选模板实际结构优先于通用视觉建议。此修复约束之后的生成与修改，不声称已自动修复所有历史站点。

## 七项交付

1. 修正 Shop 读取元信息与接入规则；禁止普通字符、Emoji 充当图标，禁止自绘 SVG 替代商品图/Banner。
2. 主技能要求浏览、详情、加购/收藏、结算与订单确认闭环；SDK 提供登录守卫、提示/跳转及站内 returnTo 检查。游客写入继续被拒绝，退出后可再次触发登录提示。旧项目 SDK 保留，需在修改旧站时显式接入同样行为。
3. website-copywriter：网站标题、页脚、About Us、联系和政策等非商品文案；按目标国家生成虚构联系资料，手机号排除连续数字，邮箱使用示例域名；不生成商品文案/价格。
4. generate-mock-data：采用用户指定的 2026年7月01日_demo3 来源，原文快照与 SHA256 留存；适配当前工具与 SDK，主技能只负责路由。修正来源示例 ID 与假图要求，不凭空伪造商品图片。
5. 画布 PC 每行5页、Tablet/Mobile 每行7页；新增 website_screenshot 工具和 CLI action:screenshot，指定页面返回全页 PNG 与文件路径。等待 load、websiteReady、字体、图片解码、懒加载和稳定布局；缺图/脚本错误/超时失败。使用独立浏览器会话，不复制画布里的登录/草稿状态，需本机 Chrome。
6. website-image-generator：调用宿主 image_gen 生成 Logo、Banner、About Us、图片 ICON 等位图，排除商品图和头像，维护真实文件引用与素材记录。
7. website-acceptance：覆盖页面完整性、排版、多端布局、素材、浏览、账户、登录门槛、购物车/收藏、订单与结算、异常资源；仅用户明确要求时调用，allow_implicit_invocation=false。

## 验证

2026-11-11 已通过：TypeScript 检查、Vite/tsup 构建、独立安装包冒烟、项目隔离/增量刷新、资源代理、commerce、templates、新增 features 和画布 visual 回归。

新增测试实际渲染四个 Shop，在375/768/1280核对2/3/4列、侧栏显隐、移动筛选和grid/list切换；检查游客提示/跳转与拒绝写入、returnTo校验、退出重置、账户注册、购物车/收藏及订单创建；核对完整PNG尺寸包含异步页脚和懒加载图片，破图与错误项目被拒绝；核对画布每行5/7页。既有画布回归确认14页无重叠、交互正常、参考站目录哈希未变化。

pnpm 在当前沙箱的全局环境目录初始化失败，因此使用同一依赖中的 tsc、Vite、tsup 和测试脚本直接运行。旧冒烟首次被外部资源网络权限阻断，在允许只读网络访问后通过。没有执行真实支付，也没有运行新增网站验收技能；技能定义/路由验证不等于每个未来生成网站已通过端到端验收。

源码与 dist 已更新。当前聊天加载的插件缓存仍为0.6.7；重新安装/重载本地插件后才会暴露0.7.0的新技能和 website_screenshot 工具。未修改版本缓存或自动覆盖历史项目。
