# ProductList-03

轮播滑动式商品列表板块组件，集成 Swiper 轮播容器展示热销商品卡片。

## 区域划分
- `section-title`: 居中板块标题骨架占位区域。
- `product-slider`: Swiper 轮播轨道及左右切换按钮导航区域。

## 尺寸与响应式
- 桌面端（>= 1024px）：单屏展示 5 个商品卡片，间距 24px。
- 平板端（768px - 1024px）：展示 4 个商品卡片，间距 20px。
- 小平板端（640px - 768px）：展示 3 个商品卡片，间距 16px。
- 移动端（< 640px）：展示 2 个商品卡片，间距 12px。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `containerSelector` | 轮播滑块容器选择器 | `string` | `'#product-slider-03'` |

## 事件机制
- `product-navigate`: 点击卡片时由卡片派发冒泡的商品跳转事件。

## 独立使用说明
板块采用纯 HTML 模板与原生 jQuery 初始化脚本，支持在页面任意容器中独立引入执行。
