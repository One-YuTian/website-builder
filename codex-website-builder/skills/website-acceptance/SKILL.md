# 网站验收（手动触发）

不因建站、改页、生成完成或截图自动调用。用户明确要求验收才执行；已有站点复用当前项目，不重建站点、不重建数据。读取页面计划、模板绑定、设计及实际文件。此处验收的是网站功能与视觉，不调用旧 templates audit 冒充测试，不输出虚构还原度分数。

1. 页面完整：逐项对照计划及导航，首页/Shop/详情/心愿单/购物车方案/结算/登录注册/About/联系/政策实际存在；Header在桌面及移动菜单均含可用的Home/Shop/About Us/Contact Us四项，无死链、404、缺失组件；drawer模式不要求cart.html。
2. 布局与排版：375/768/1280（另有宽屏则补测）逐页渲染，检查移动<768px的html根字号为12px（补测767/768断点）、版心、溢出、遮挡、留白、字阶、长标题截断、表单标签、按钮可点击、正文可读性。对照选定Shop+Card的实际代码检查区域、列数、图片比例、移动筛选/抽屉与Swiper；不凭概述推断。
3. 素材：Logo必须为透明无额外边距的真实图片，favicon为1:1且head引用正确；首页在基础板块外有1–2个不重复的额外板块；图片完整加载与解码，无破图/伪造SVG商品或Banner；无字符/Emoji图标，图标体系一致；字体和第三方库使用在线CDN；各Banner/About图不得复用同一张，关键主体在可见版心安全区内。用 website_screenshot 获取代表页面各端全页图，查看实际图片，不能只做静态扫描。
4. 浏览交互：搜索、分类、价格过滤、排序、分页组合；重置页码、空结果、未知商品、详情规格与数量、移动导航/筛选/轮播正常；Header已有分类时首页不重复分类套件；按钮/控件状态风格统一；所有蒙层空白可关闭且点击面板不关闭，焦点和滚动恢复。
5. 登录注册：用专用演示账号测试表单校验、重复邮箱、错误密码、成功注册与登录、退出和再次登录。未登录点击加购/收藏必须通过全站Toast显示提示后跳登录，不使用原生alert；每页Toast组件与API均可用且不重复；游客不写状态。returnTo拒绝外部URL；登录后正确返回，账户切换购物车/收藏隔离。
6. 购物车/心愿单：已登录加购/收藏、数量更新/删除/取消收藏、徽标跨组件同步，真实数值价格与折扣，购物车行ID不误用商品ID，持久化与空状态正确。
7. 结算下单：未登录/空车拦截，必填/无效字段、重复提交、失败重试；演示下单成功生成订单快照、订单确认、清空购物车且可查询。只在本地/测试支付环境执行，真实交易停留在不可逆提交前，明确记录未执行步骤。
8. 控制台/资源/网络：记录脚本异常、失败请求和加载超时，不把静态文件存在等同成功。不修改用户真实订单或账号，测试账号数据与截图单独标记。

在生产目录外的 metadata_directory/artifacts/acceptance/ 保存各端截图和 report.json/report.md；每项包含页面、设备、步骤、期望、实际、pass/fail/blocked/not-tested、证据路径及严重程度。报告区分实际测试与未验证项，不以截图等同交易成功。发现问题先记录，用户已授权修复时修复并复测受影响项。最终给出通过项、阻断问题及未测试项和报告链接，不在未运行浏览器时宣称通过。

核对Toast的WebComponent生命周期与断开清理；商品JSON通过导入工具/SDK读取且源数据未改，分类视图过滤完整；PC边缘对齐且Logo无多余边距，单页逻辑在HTML script，详情长内容可展开/分页且没有丢失。CDN应避免jsDelivr/jsdeliver。
