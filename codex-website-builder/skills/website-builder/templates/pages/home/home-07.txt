## Overview

Modern home decor and aesthetic living homepage assembled from home lifestyle navigation header, inspiring living hero carousel, bestselling home goods grid, service guarantee bar, and footer.

### Component Chain
`home-07: header-07 -> carousel-01 -> productlist-01 -> services-02 -> footer-01`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-07` | `<header-07>` | Home aesthetic lifestyle navigation header with room and department categories |
| `Carousel-01` | `<carousel-01>` | Hero responsive home inspiration carousel showcasing lifestyle spaces |
| `ProductList-01` | `<productlist-01>` | Bestselling home decor products grid showcase |
| `Services-02` | `<services-02>` | Home delivery guarantees, replacement protection, and customer service bar |
| `Footer-01` | `<footer-01>` | Global site footer with sitemap links and newsletter subscription |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
