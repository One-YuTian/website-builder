# Card-02

全功能电商商品卡片组件，包含收藏夹按钮、折扣角标、多星评分与全宽加购操作按钮。

## 区域划分
- `image-area`: 顶部或左侧商品主图及浮动操作按钮区域。
- `content-area`: 包含双行标题、星级评价、价格和加购操作区域。

## 尺寸与响应式
- 网格视图：纵向流式自适应父级列宽，图片比例保持 1:1 正方形。
- 列表视图：横向图文展开，图片区域固定宽度 112px（小屏）或 192px（大屏）。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `product-id` | 商品唯一标识 | `string` | `'product-01'` |
| `view-mode` | 排版布局模式（`grid` 或 `list`） | `string` | `'grid'` |
| `discounted` | 折扣状态与原价显示标记 | `boolean` | `false` |

## 事件机制
- `product-navigate`: 点击卡片或加购按钮时派发的商品交互事件。

## 独立使用说明
组件作为独立 WebComponent 引入，可直接嵌入网格列表或轮播板块容器中使用。
