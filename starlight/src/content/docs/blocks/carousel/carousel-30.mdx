## Overview

Full-width hero visual carousel showcase block, supporting multi-aspect ratio scaling, touch drag gestures, auto-rotation timer, bottom dot pagination indicators, and left/right navigation arrows, with dedicated breakpoint viewport adaptation.

### Layout & Detailed Region Breakdown
- `carousel-stage`: **Full-width slide stage region**, wrapped in responsive Swiper container, desktop fixed height 500px~550px, mobile adapting to 16:9 or 50:21 aspect ratio, embedding multiple full-bleed slides.
- `slide-image`: **Banner imagery region**, filling slide viewport with large image placeholder skeleton and gradient overlay mask to preserve text contrast.
- `text-overlay`: **Textual content overlay region**, absolutely positioned on the left or center, containing prominent campaign title skeleton, subtitle description, and high-radius Shop Now CTA button.
- `pagination`: **Bottom dot indicator region**, floating centered at the bottom, containing 3~5 round or pill indicators, active slide highlighted with elongated primary pill.
- `arrow-controls`: **Slide navigation arrow controls**, semi-transparent circular navigation buttons floating on left and right edges with hover highlight effects.

### Dimensions & Responsiveness
- Follows global design system, outer container uses `content-container` with PC max content width 1200px centered.
- Desktop (1024px+): Fixed height 500px~550px with stable text overlay alignment.
- Mobile (under 1024px): Adapts to 16:9 or 50:21 aspect ratio with smooth swipe touch gestures.

### Attributes & Props
| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| `stageSelector` | Mount container selector | `string` | `'#carousel-stage'` |
| `interval` | Auto-play interval in milliseconds | `number` | `5000` |
| `paused` | Whether auto-rotation is paused | `boolean` | `false` |

### Events
- `carousel-navigate`: Dispatched when clicking a carousel slide banner.
- `carousel-change`: Dispatched when slide transition finishes, providing current active index.
