# Home-09

手工艺文创与天然羊绒工坊首页，由民族特色手作导航、手作工坊大幅轮播、工艺分类导购图文网格、匠心单品陈列瀑布流及页脚组合而成。

### 组合链路
`home-09：header-09->carousel-12->categories-02->productlist-01->footer-01`

### 使用的组件 (Included Components)
- `Header-09` (`<header-09>`): 手工艺特色文创吸顶导航栏，传达天然手工工坊质感。
- `Carousel-12` (`<carousel-12>`): 手工艺工坊首屏大幅轮播海报，展示羊绒编织与手工细节。
- `Categories-02` (`<categories-02>`): 手工工艺分类图文导航卡片（羊绒围巾、木雕、铜器等）。
- `ProductList-01` (`<productlist-01>`): 匠心手作甄选商品陈列瀑布流。
- `Footer-01` (`<footer-01>`): 工坊全球配送服务与原产地保障页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
