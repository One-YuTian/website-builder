## Overview

Mobile communications and smart devices hub homepage assembled from dual-layer tech header, mobile hardware hero carousel, brand zones & device categories, wearables & TWS flash sale, official inspection service bar, smart devices grid, and footer.

### Component Chain
`home-23: header-03 -> carousel-28 -> categories-07 -> flashsale-08 -> services-05 -> productlist-01 -> footer-01`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-03` | `<header-03>` | Smart communication hub dual-layer navigation header with deep search |
| `Carousel-28` | `<carousel-28>` | Mobile hardware and 5G smartphones hero banner carousel |
| `Categories-07` | `<categories-07>` | Brand zones and device category shortcuts (phones, tablets, smartwatches) |
| `FlashSale-08` | `<flashsale-08>` | Wearables and TWS earbuds limited-time countdown flash sale |
| `Services-05` | `<services-05>` | Official device inspection report, national warranty, and return service bar |
| `ProductList-01` | `<productlist-01>` | Featured smart mobile devices and accessories showcase grid |
| `Footer-01` | `<footer-01>` | Official communication hub service footer with newsletter signup |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
