# Header-07

三栏对称式简约电商导航栏组件，标志居中展示，两侧分别排布分类导航与功能操作入口。

## 区域划分
- `desktop-nav`: 桌面端左侧主要导航链接区域。
- `logo`: 居中展示的品牌标识展示区域。
- `auth`: 右侧用户身份登录与面板操作区域。
- `mobile-drawer`: 移动端侧滑导航菜单区域。

## 尺寸与响应式
- 桌面端：导航栏高度固定为 60px，左中右三区域通过 flex 均分对齐。
- 移动端：导航收起为汉堡菜单，唤起全屏半透明抽屉层。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `is-logged-in` | 用户登录状态标记 | `boolean` | `false` |
| `cart-count` | 购物车徽标商品数量 | `number` | `0` |
| `wishlist-count` | 收藏夹徽标商品数量 | `number` | `0` |
| `theme` | 主题反转模式（深色/浅色） | `string` | `'dark'` |

## 事件机制
- `header-navigate`: 导航栏各项跳转触发事件。

## 独立使用说明
组件作为独立 WebComponent 引入，支持动态修改 `theme` 属性实现色彩反转。
