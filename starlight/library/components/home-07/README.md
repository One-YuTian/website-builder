# Home-07

现代家居软装与生活美学首页，由生活美学导航、场景灵感轮播、热销家居好物网格、专属服务承诺条及全局页脚组合而成。

### 组合链路
`home-07：header-07->carousel-01->productlist-01->services-02->footer-01`

### 使用的组件 (Included Components)
- `Header-07` (`<header-07>`): 家居生活美学风格吸顶导航，提供清晰的房间与品类导览。
- `Carousel-01` (`<carousel-01>`): 首屏居家灵感场景轮播海报，营造舒适生活方式体验。
- `ProductList-01` (`<productlist-01>`): 热销家居美物商品网格，展示精选摆件与家具用品。
- `Services-02` (`<services-02>`): 家居专属服务承诺条（送货上门、破损包赔、正品保障）。
- `Footer-01` (`<footer-01>`): 生活美学馆全局底部矩阵与邮件订阅专区。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
