# Home-13

潮流街区态度与潮流先锋商城首页，由现代集市导航、街头潮流大幅轮播、风格导购分类卡片、限量联名通栏、潮流尖货网格及页脚组合而成。

### 组合链路
`home-13：header-05->carousel-16->categories-03->promotion-01->productlist-01->footer-02`

### 使用的组件 (Included Components)
- `Header-05` (`<header-05>`): 潮流集市现代吸顶导航栏，适配年轻态受众操作习惯。
- `Carousel-16` (`<carousel-16>`): 潮流街区首屏态度轮播海报，呈现前卫穿搭与态度主张。
- `Categories-03` (`<categories-03>`): 潮流分类风格导购卡片（卫衣、工装、板鞋、配饰）。
- `Promotion-01` (`<promotion-01>`): 限量联名胶囊系列视觉通栏。
- `ProductList-01` (`<productlist-01>`): 潮流尖货爆款单品瀑布流展示。
- `Footer-02` (`<footer-02>`): 潮流社群与品质售后保障页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
