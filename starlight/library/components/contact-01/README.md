# Contact-01

联系我们客服与商业咨询页面，整合企业联系方式卡片矩阵（地址、电话、邮箱、工作时间）、在线留言反馈表单以及全宽互动地理位置地图。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），PC 最大内容宽度 1200px 居中排版。
- 桌面端（1024px+）：左右 1:1 双栏并排（左侧联系卡片，右侧反馈表单）。
- 移动端（小于 768px）：自适应为单列垂直排布，表单按键全宽拉伸。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `formTitle` | 表单大标题文案 | `string` | `'Get in Touch'` |

### 事件机制
- `contact-submit`: 提交留言表单时派发事件，携带表单数据对象。
