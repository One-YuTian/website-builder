# Login-01

用户身份登录鉴权页面，采用居中高圆角卡片，包含品牌 LOGO 骨架、邮箱/密码输入字段、记住我复选框、忘记密码入口、第三方社交登录与注册跳转。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 居中卡片最大宽度 440px，上下留白 80px，自适应视口垂直居中对齐。
- 移动端：宽度 calc(100vw - 32px)，按键高度不低于 48px。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `title` | 页面登录大标题 | `string` | `'Welcome Back'` |

### 事件机制
- `auth-login`: 提交登录表单时派发，携带用户凭据对象。
- `auth-navigate`: 点击注册或忘记密码链接时派发跳转事件。
