# Home-12

硬核户外装备与徒步露营商城首页，由科技吸顶导航、硬核户外大幅轮播、专业保障服务条、户外特惠秒杀、核心装备网格及页脚组合而成。

### 组合链路
`home-12：header-03->carousel-14->services-02->flashsale-01->productlist-04->footer-01`

### 使用的组件 (Included Components)
- `Header-03` (`<header-03>`): 双层户外装备导航栏，快速定位徒步、露营、攀登品类。
- `Carousel-14` (`<carousel-14>`): 户外极限探险首屏轮播海报，强化硬核机能与户外场景。
- `Services-02` (`<services-02>`): 户外专业装备终身质保与安全检验承诺条。
- `FlashSale-01` (`<flashsale-01>`): 露营探险限时特惠秒杀专区。
- `ProductList-04` (`<productlist-04>`): 核心探险装备精选展示网格。
- `Footer-01` (`<footer-01>`): 户外探险装备站全局页脚与会员社群订阅。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
