# Home-03

数码科技与智能硬件垂直电商首页，由科技感双层吸顶导航、首屏轮播海报、限时秒杀专区、新品活动推荐通栏、精选数码商品瀑布流及页脚组合而成。

### 组合链路
`home-03：header-03->carousel-01->flashsale-01->promotion-02->productlist-04->footer-01`

### 使用的组件 (Included Components)
- `Header-03` (`<header-03>`): 科技感双层吸顶导航，含多语言/货币占位、搜索栏、分类菜单及购物车。
- `Carousel-01` (`<carousel-01>`): 首屏响应式活动轮播横幅，支持高分辨率海报展示与手势滑动。
- `FlashSale-01` (`<flashsale-01>`): 限时倒计时特惠秒杀板块，内置进度条特价商品卡片。
- `Promotion-02` (`<promotion-02>`): 新品发布与重点品类促销推广通栏。
- `ProductList-04` (`<productlist-04>`): 精选数码科技商品网格，支持响应式多列商品卡片陈列。
- `Footer-01` (`<footer-01>`): 全局底部矩阵，包含品牌介绍、服务条约、邮件订阅及支付图标。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
