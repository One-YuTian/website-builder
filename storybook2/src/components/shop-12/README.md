# Shop-12

包含预设价格区间筛选、重置清空与网格/列表视图切换的商城页面组件，支持双视图排版与多条件过滤。

## 区域划分
- `page-header`: 顶部商城大标题与副标题描述区域。
- `sidebar`: 桌面端左侧分类单选与预设价格范围档位侧边栏，含重置按钮。
- `toolbar`: 右侧主内容区工具栏，包含结果统计、排序下拉及网格/列表视图切换按钮。
- `products-grid`: 2 列至 3 列网格或垂直单列列表容器区域。

## 尺寸与响应式
- 页面容器：由全局 `content-container` 控制内容最大宽度。
- 侧边栏：桌面端固定宽度 256px 并吸顶停靠（`sticky top-24`），移动与平板端提供筛选侧边抽屉。
- 视图切换：网格模式下移动端 2 列、平板与桌面端 3 列，列表模式下垂直流式全宽展开。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `sortOrder` | 价格排序规则（`default` / `price-low` / `price-high`） | `string` | `'relevance'` |

## 事件机制
- `product-navigate`: 子级商品卡片点击时冒泡派发的商品交互事件。

## 独立使用说明
作为独立页面级模板使用，直接渲染基础 HTML 结构并通过内置脚本驱动卡片与排序交互。
