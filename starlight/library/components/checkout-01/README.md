# Checkout-01

全流程结账与订单确认页面，包含配送收货地址录入表单、支付方式选择器以及右侧粘性定位的订单费用明细核算栏。

### 强制规范要求
1. **左侧表单卡片不使用步骤序号**：收货地址与支付方式卡片顶部直接呈现标题骨架，无需展示 1、2 等圆形数字序号。
2. **零货币符号与缩写**：全局绝不包含任何国家货币符号、单位名称或硬编码文本（如 COD 标签），数值展示使用纯数字或占位骨架。
3. **支付方式选项规范**：底部支付方式必须包含且仅包含两项：
   - **货到付款（Cash on Delivery）**：默认选中激活状态（Radio checked）；
   - **在线支付（Online Payment）**：禁用不可选状态（Radio disabled, opacity-60, cursor-not-allowed）。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 Tailwind 居中容器（`w-full max-w-content mx-auto px-4 lg:px-6`），PC 最大内容宽度 1200px 居中排版。
- 桌面端（1024px+）：左右 7:5 不对称双栏排版（左侧表单，右侧粘性结算汇总卡片）。
- 移动端（小于 1024px）：单列垂直排布，结算栏贴底或置于表单下方。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `step` | 当前所处结账步骤（1, 2, 3） | `number` | `1` |

### 事件机制
- `checkout-submit`: 点击提交订单时派发结账支付事件，携带完整地址与支付凭据。
