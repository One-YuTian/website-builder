## Overview

Smartphones and mobile tech accessories homepage assembled from standard navigation header, flagship smartphone hero carousel, accessories countdown flash sale, best-selling smart devices grid, and official footer.

### Component Chain
`home-17: header-01 -> carousel-20 -> flashsale-01 -> productlist-01 -> footer-01`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-01` | `<header-01>` | Standard sticky navigation header with search and category shortcuts |
| `Carousel-20` | `<carousel-20>` | Flagship smartphone hero carousel highlighting hardware specs and visuals |
| `FlashSale-01` | `<flashsale-01>` | Mobile accessories and charging gear countdown flash sale section |
| `ProductList-01` | `<productlist-01>` | Featured best-selling smartphones and smart gadgets showcase grid |
| `Footer-01` | `<footer-01>` | Official device verification, warranty support, and site footer |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
