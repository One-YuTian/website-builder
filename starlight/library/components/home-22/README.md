# Home-22

潮玩模型与机械拼插积木首页，由潮玩吸顶导航、限量模型轮播、热门IP系列分类卡、机械动力拼插网格、拼搭挑战赛通栏、手办盲盒全览及玩家保障页脚组合而成。

### 组合链路
`home-22：header-02->carousel-01->categories-06->productlist-02->promotion-01->productlist-01->footer-02`

### 使用的组件 (Included Components)
- `Header-02` (`<header-02>`): 潮玩模型吸顶导航栏，含通告栏与核心品类索引。
- `Carousel-01` (`<carousel-01>`): 限量机械拼装与潮玩模型首屏轮播海报。
- `Categories-06` (`<categories-06>`): 潮流IP与主题系列分类卡片（科幻机甲、街景建筑、超跑车模）。
- `ProductList-02` (`<productlist-02>`): 热门机械动力与高难度拼插积木网格。
- `Promotion-01` (`<promotion-01>`): 玩家拼搭挑战赛与粉丝节活动通栏。
- `ProductList-01` (`<productlist-01>`): 潮流手办、盲盒与周边好物陈列瀑布流。
- `Footer-02` (`<footer-02>`): 潮玩玩家社群与无忧补件服务保障页脚。

### 尺寸与响应式
- 整体遵循全站最大内容宽度（`w-full max-w-content mx-auto px-4 lg:px-6`）。
- 移动端：自适应单列流式布局，轮播与板块支持平滑手势触摸滑动与多端自适应。
