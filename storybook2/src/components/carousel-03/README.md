# Carousel-03

首页全宽主视觉轮播展示板块，支持多画幅等比缩放、触控拖拽滑动、自动轮播定时器、底部圆点分页指示器与左右切换箭头，桌面端与移动端按断点提供专用画幅适配。

### 区域划分与内容说明
- `carousel-stage`: **全宽主幻灯片舞台区**，外层包裹响应式 Swiper 容器，桌面端固定 500px~550px 高度，移动端自适应为 16:9 或 50:21 宽高比；内部包含多个全画幅横幅轮播幻灯片项目。
- `slide-image`: **横幅大图展示区**，填满整个幻灯片画幅，内嵌大画幅图片占位骨架与平滑明暗渐变遮罩层，保证前景文字的高对比度可读性。
- `text-overlay`: **图文内容浮层区**，居左或居中绝对定位，包含 1 行醒目的大促主题大标题骨架、1~2 行活动副说明文本骨架，以及 1 枚高圆角“立即选购（Shop Now）”行动按钮（CTA）。
- `pagination`: **底部指示器导航区**，居中悬浮于轮播底部，包含 3~5 个圆形或胶囊形分页圆点指示器，当前激活的幻灯片指示器呈现为主色加长胶囊样式。
- `arrow-controls`: **左右切换控制区**，位于幻灯片左右两侧的半透明悬浮圆形箭头按钮，支持前后切页与鼠标悬停高亮。

### 尺寸与响应式
- 遵循全局设计规范，外层容器采用 `content-container`，PC 最大内容宽度 1200px 居中对齐。
- 桌面端（1024px+）：高度固定为 500px~550px，图文浮层保持稳定对齐。
- 移动端（小于 1024px）：自适应收缩为 16:9 或 50:21 高宽比，支持手势横滑平滑翻页。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `stageSelector` | 初始化挂载容器选择器 | `string` | `'#carousel-01-stage'` |
| `interval` | 自动轮播切换时间间隔（毫秒） | `number` | `5000` |
| `paused` | 是否暂停自动播放 | `boolean` | `false` |

### 事件机制
- `carousel-navigate`: 点击轮播幻灯片时派发页面跳转事件。
- `carousel-change`: 轮播切换到新滑块时派发，携带当前活跃索引参数。
