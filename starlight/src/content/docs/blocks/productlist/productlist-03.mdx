## Overview

Core e-commerce product shelf grid block, integrating section title, fast category filter tabs, 4~5 column responsive product card matrix, and bottom View All CTA.

### Layout & Detailed Region Breakdown
- `section-header`: **Section headline region**, containing left-aligned bold section title skeleton (e.g. Featured Products), category subtitle description, and right-aligned View All link.
- `filter-tabs`: **Fast category filter tabs region**, horizontally aligning pill-shaped category tabs (All, New Arrivals, Best Sellers, On Sale), switching displayed goods upon click.
- `product-grid`: **Responsive product card showcase grid**, desktop displaying 4~5 equal columns, tablet 3 columns, mobile adapting to 2 compact columns, embedding full product cards.
- `load-more`: **Bottom action region**, centered outline Load More button skeleton supporting dynamic product batch loading.

- Outer container strictly follows `content-container` with PC max content width 1200px centered.
- Desktop (1024px+): 4~5 column grid layout with 16px~24px gutters.
- Tablet (768px~1023px): Adapts to 3-column grid.
- Mobile (under 768px): Adapts to 2 compact columns with 12px gap.
