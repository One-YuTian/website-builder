# Card-19

紧凑型商品卡片组件，具有 4:3 比例商品主图、大圆形折扣徽章、星级评分与底部扁平加购操作条。

## 区域划分
- `image-area`: 顶部或左侧 4:3 比例主图区域，包含左上圆形折扣徽章与右上心形收藏按钮。
- `content-area`: 商品标题、五星评分、价格对照及全宽加购操作按钮区域。

## 尺寸与响应式
- 网格视图：纵向流式自适应父级网格，主图比例为 4:3。
- 列表视图：横向图文排版，主图区域宽度为 128px（小屏）或 192px（大屏）。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `product-id` | 商品唯一标识 | `string` | `'product-01'` |
| `view-mode` | 排版布局模式（`grid` 或 `list`） | `string` | `'grid'` |
| `discounted` | 折扣状态与原价显示标记 | `boolean` | `false` |

## 事件机制
- `product-navigate`: 点击卡片、加购按钮或收藏夹时派发商品交互事件。

## 独立使用说明
组件作为独立 WebComponent 引入，可直接嵌入网格列表或轮播板块容器中使用。
