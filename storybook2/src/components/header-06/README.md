# Header-06

双栏式电商导航栏组件，包含顶部搜索与操作区以及次级居中分类导航栏。

## 区域划分
- `top-bar`: 顶部操作栏，包含品牌标志、搜索栏、用户认证、收藏夹与购物车入口。
- `menu-bar`: 桌面端次级居中分类导航链接区域。
- `mobile-drawer`: 移动端侧边抽屉菜单与导航区域。

## 尺寸与响应式
- 桌面端：顶部操作栏高度约 56px，次级菜单栏高度约 44px，内容自适应最大内容宽度居中。
- 移动端：次级菜单折叠收纳至 288px 宽度的全高侧边抽屉。

## 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `is-logged-in` | 用户登录状态标记 | `boolean` | `false` |
| `cart-count` | 购物车徽标商品数量 | `number` | `0` |
| `wishlist-count` | 收藏夹徽标商品数量 | `number` | `0` |
| `theme` | 主题反转模式（深色/浅色） | `string` | `'dark'` |

## 事件机制
- `header-navigate`: 导航跳转触发事件，返回目标与参数。
- `header-search`: 搜索表单提交事件，携带搜索关键词。
- `header-search-input`: 搜索框即时输入事件，用于联想词补全。

## 独立使用说明
组件可作为独立 WebComponent 标签引入，支持调用实例方法 `toggleMobileMenu()` 与 `updateCart()`。
