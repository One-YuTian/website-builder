# Register-01

用户注册新账号页面，包含全名、邮箱、独立国际区号的手机号码输入组、密码强度检测、确认密码、服务条款同意勾选框、注册提交按钮与已有账号直接登录入口。

### 强制规范要求
- **国际区号独立成块（Separated Country Code Prefix）**：手机号输入框必须将国际区号（如 `+1` / `+63` / `+55` 等）作为独立的左侧前缀块（`inline-flex items-center px-3.5 rounded-l-xl border border-r-0 bg-accent/40 text-sm font-semibold select-none`）单独拎出并与主输入框组合显示，严禁将区号与手机号混在同一个纯文本框内输入。

### 区域划分
本组件各功能区域通过英文注释直接标注于代码实现中。


### 尺寸与响应式
- 居中卡片最大宽度 480px，自适应屏幕垂直居中排版。
- 移动端：宽度 calc(100vw - 32px)，保持紧凑边距与适宜触控高度。

### 属性与接口
| 属性名 | 属性说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `title` | 注册页面大标题 | `string` | `'Create Account'` |

### 事件机制
- `auth-register`: 提交注册表单时派发，携带注册信息对象。
- `auth-navigate`: 点击已有账号登录时派发跳转事件。
