# 0.8.1

- 当前对话打开画布时，按真实thread_id直接恢复该会话项目详情；无绑定会话/项目时仍进入首页，不使用全局最近项目替代。手动返回首页不受轮询影响。
- open_canvas支持可选thread_id，并通过MCP App工具结果将当前对话传入面板，兼容全局入口没有注入会话ID的情况。
- 新增website_images工具，在生图前登记路径与尺寸，持久化生成中/失败/完成状态。画布展示对应比例加载占位，文件落盘后自动展示；支持失败提示及重试，重新生成不会以旧图误报完成。
- 图片任务状态保存在SQLite，进程重启/面板重开后保留；不向生产目录写占位图或管理文件。图片解码失败时显示错误，复制按钮仅在真实图片加载后启用。
- 主建站技能和图片生成技能同步采用任务登记与当前会话打开流程。
