## Overview

Brand discount deals and multi-category retail homepage assembled from high-tech navigation header, hero banner carousel, brand special offer promotional block, value countdown flash deal section, trending products grid, and footer.

### Component Chain
`home-11: header-03 -> carousel-03 -> promotion-05 -> flashsale-03 -> productlist-01 -> footer-01`

### Included Components
| Component | Custom Element | Role & Function |
| --- | --- | --- |
| `Header-03` | `<header-03>` | Dual-layer sticky navigation header with search and category shortcuts |
| `Carousel-03` | `<carousel-03>` | Hero responsive full-width banner carousel for joint brand campaigns |
| `Promotion-05` | `<promotion-05>` | Brand special offer promotional block showcasing partner brand discounts |
| `FlashSale-03` | `<flashsale-03>` | Value countdown flash deal section with time-limited discounts |
| `ProductList-01` | `<productlist-01>` | Featured trending products grid showcase with add-to-cart actions |
| `Footer-01` | `<footer-01>` | Global comprehensive site footer with sitemap links and newsletter signup |

### Dimensions & Responsiveness
- Aligned to global content width (`w-full max-w-content mx-auto px-4 lg:px-6`).
- Mobile: Fully responsive stacked layout with native touch carousel gestures.
